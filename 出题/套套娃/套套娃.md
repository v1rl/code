### 题目描述

给定一个长度为 $n$ 的序列 $A = [a_1, a_2, \dots, a_n]$。

定义序列 $P$，其中第 $i$ 项 $P_i$ 的计算公式如下：

$$P_i = \sum_{k=1}^i (i - k + 1) \times a_k$$

请计算并输出序列 $P$ 中的每一个元素。

------

### 输入格式

第一行包含一个正整数 $n$。

第二行包含 $n$ 个非负整数 $a_1, a_2, \dots, a_n$，相邻整数之间用空格分隔。

------

### 输出格式

输出一行 $n$ 个整数，表示 $P_1, P_2, \dots, P_n$，相邻整数之间用单空格分隔。

------

### 样例输入

Plaintext

```
5
1 2 3 4 5
```

### 样例输出

Plaintext

```
1 4 10 20 35
```

------

### 数据范围

- $1 \le n \le 10^5$
- $0 \le a_i \le 10^5$
