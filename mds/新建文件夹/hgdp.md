以下是详细的思路解析和 C++ 代码实现。

### 一、 核心洞见与思路解析

#### 1. 信号的独立性 (降维打击)

题目要求所有的 $M$ 种信号都达到公平状态，并且修改操作针对的是特定的某种信号。这意味着 **$M$ 种信号之间是完全独立的**。

我们不需要把 $M$ 种信号混在一起考虑。我们可以针对每一种信号 $j$ 单独计算：当根节点（服务器）是 $r$ 时，使得信号 $j$ 达到公平状态的最小代价是多少。最后将这 $M$ 个代价相加，就是根节点为 $r$ 时的总代价。

#### 2. 公平状态的两种选择

对于选定的根节点 $r$ 和某一种特定信号 $j$，树上的终端客户（度数为 $1$ 的叶子节点，不含 $r$）共有 $K$ 个。

假设在不进行任何操作的情况下：

- 有 $cnt_1$ 个客户**能**接收到信号 $j$（路径上有信号）。

- 有 $cnt_0$ 个客户**不能**接收到信号 $j$（路径上无信号）。

  显然 $cnt_1 + cnt_0 = K$。

为了达到“绝对公平”（要么全收到，要么全收不到），我们只有两种策略：

- **策略A（全都不接收）**：给那 $cnt_1$ 个能接收到的客户安装“屏蔽器”，代价为 $cnt_1$。

- **策略B（全都接收）**：给那 $cnt_0$ 个不能接收的客户安装“放大器”，代价为 $cnt_0$。

  所以，对于根节点 $r$ 和信号 $j$，最小代价就是 **$\min(cnt_0, cnt_1)$**。

#### 3. 树上路径转化为连通块 (最关键的一步)

如何快速求出 $cnt_0$ 呢？

一条从 $r$ 到客户 $L$ 的路径上**没有**信号 $j$，等价于：**这条路径上的每一个节点都没有部署信号 $j$**。

如果我们将所有**没有部署信号 $j$ 的节点**看作图中的点，它们会构成若干个**连通块 (Connected Components)**。

根据树的性质：

- 如果根节点 $r$ 部署了信号 $j$，那么从 $r$ 出发的任何路径必然带有信号 $j$。此时 $cnt_0 = 0$。
- 如果根节点 $r$ **没有**部署信号 $j$，那么它必然属于某个“无信号连通块” $C$。从 $r$ 出发、且路径上没有信号的节点，**完全等价于连通块 $C$ 内的其他节点**。
- 因此，此时的 $cnt_0$ 就等于：**连通块 $C$ 中包含了多少个终端客户（原树的叶子节点）**。

#### 4. 算法流程归纳

1. 统计原树中所有度数为 1 的节点，总数为 $TotL$。
2. 对每一种信号 $j \in [1, M]$ 进行独立遍历：
   - 找出图中所有“没有信号 $j$ 的节点”构成的连通块。
   - 统计每个连通块内部包含了多少个原树的叶子节点。
   - 遍历所有可能的中央服务器 $r \in [1, N]$：
     - 计算当 $r$ 为根时，真正的终端客户数量 $K_r = TotL - [deg(r) == 1]$。
     - 如果 $r$ 有信号 $j$，$cnt_0 = 0$。
     - 如果 $r$ 无信号 $j$，$cnt_0 = $ 其所在连通块内的叶子总数 $- [deg(r) == 1]$。
     - 该信号带来的代价为 $\min(cnt_0, K_r - cnt_0)$，累加到答案 $Ans[r]$ 中。
3. 最终输出 $Ans[1 \dots N]$ 即可。

### 二、 复杂度分析

- **时间复杂度：** 对于每种信号，我们只需要进行一次 BFS 或 DFS 来划分连通块，时间复杂度是 $O(N)$。一共有 $M$ 种信号，总时间复杂度为 $\mathcal{O}(N \times M)$。由于 $M \le 6$，这实际上就是线性的，可以轻松通过 $N = 10^5$ 或更大的数据规模。
- **空间复杂度：** 图的存储 $O(N)$，连通块和状态数组 $O(N)$。总空间复杂度 $\mathcal{O}(N)$。

### 三、 优雅的 C++ 代码实现

*(注：由于截图未提供具体输入输出格式，这里采用最标准的竞赛图论输入格式：先输入 $N$ 和 $M$，接着 $N-1$ 行输入树的边，最后 $N$ 行每行输入 $M$ 个 $0/1$ 表示每个节点是否包含这 $M$ 种信号)*

C++

```
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>

using namespace std;

int main() {
    // 优化输入输出流速度
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int N, M;
    if (!(cin >> N >> M)) return 0;

    vector<vector<int>> adj(N + 1);
    vector<int> deg(N + 1, 0);
    
    // 读入 N-1 条边，构建无根树
    for (int i = 0; i < N - 1; ++i) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
        deg[u]++;
        deg[v]++;
    }

    // has_signal[i][j] 表示节点 i 是否部署了信号 j (1-indexed)
    vector<vector<bool>> has_signal(N + 1, vector<bool>(M + 1, false));
    for (int i = 1; i <= N; ++i) {
        for (int j = 1; j <= M; ++j) {
            int val;
            cin >> val;
            has_signal[i][j] = (val == 1);
        }
    }

    // 特判 N=1 的情况
    if (N == 1) {
        cout << 0 << "\n";
        return 0;
    }

    // 统计原树中度数为 1 的总叶子数
    int total_leaves = 0;
    for (int i = 1; i <= N; ++i) {
        if (deg[i] == 1) {
            total_leaves++;
        }
    }

    // ans[r] 记录以节点 r 为中央服务器时的总最小代价
    vector<long long> ans(N + 1, 0);

    // 核心逻辑：对这 M 种信号逐一独立计算
    for (int j = 1; j <= M; ++j) {
        vector<bool> visited(N + 1, false);
        vector<int> comp_id(N + 1, 0);    // 记录每个节点所属的连通块编号
        vector<int> comp_leaves(1, 0);    // 记录每个连通块内部的原树叶子数量 (1-indexed)
        int current_comp = 0;

        // 1. 划分“无信号”连通块
        for (int i = 1; i <= N; ++i) {
            if (!has_signal[i][j] && !visited[i]) {
                current_comp++;
                int leaves_in_comp = 0;
                
                // 使用 BFS 遍历该连通块
                queue<int> q;
                q.push(i);
                visited[i] = true;

                while (!q.empty()) {
                    int u = q.front();
                    q.pop();
                    
                    comp_id[u] = current_comp;
                    if (deg[u] == 1) {
                        leaves_in_comp++; // 发现该节点是原树的叶子
                    }

                    for (int v : adj[u]) {
                        if (!has_signal[v][j] && !visited[v]) {
                            visited[v] = true;
                            q.push(v);
                        }
                    }
                }
                comp_leaves.push_back(leaves_in_comp);
            }
        }

        // 2. 枚举中央服务器 r，计算该信号带来的代价
        for (int r = 1; r <= N; ++r) {
            // K_r: 以 r 为根时，真正的终端客户数量 (排除 r 自身如果是叶子的情况)
            int K_r = total_leaves - (deg[r] == 1 ? 1 : 0);
            int cnt0 = 0; // 无法接收到信号的客户数量

            if (!has_signal[r][j]) {
                // 如果 r 本身没有信号，无法接收信号的客户就都在 r 所在的无信号连通块里
                int cid = comp_id[r];
                // 同样要排除掉 r 自身如果是叶子的情况
                cnt0 = comp_leaves[cid] - (deg[r] == 1 ? 1 : 0);
            } else {
                // 如果 r 本身就有信号，所有客户都能接收到 (cnt0 = 0)
                cnt0 = 0;
            }

            // 代价是 min(安装放大器的数量, 安装屏蔽器的数量)
            int cost = min(cnt0, K_r - cnt0);
            ans[r] += cost;
        }
    }

    // 输出最终结果
    for (int i = 1; i <= N; ++i) {
        cout << ans[i] << (i == N ? "" : " ");
    }
    cout << "\n";

    return 0;
}
```
