换根 DP（Re-rooting DP），也被称为“二次扫描法”或“上下 DP”，是树形 DP 中的一种高阶技巧。它的核心作用是**在 $O(N)$ 的时间复杂度内，求出以树上每一个节点为根时的 DP 状态**。

如果暴力求解，我们需要对每个节点进行一次 $O(N)$ 的 DFS，总复杂度为 $O(N^2)$，这在 $N \ge 10^5$ 的竞赛题中显然会 TLE。换根 DP 通过提取相邻节点状态转移的冗余信息，将复杂度降维。

### 一、 换根 DP 的核心逻辑与性质

换根 DP 的本质是**状态的剥离与重组**。它通常分为两次 DFS：

1. **第一遍 DFS（自底向上，信息汇聚）：**

   任选一个节点（通常取 1 号点）作为整棵树的初始根。进行一次常规的树形 DP，计算出每个节点 $u$ 在其**子树内**的状态，记为 $dp[u]$。

2. **第二遍 DFS（自顶向下，状态推导）：**

   这是换根的核心。当我们把根从节点 $u$ 转移到其相邻的子节点 $v$ 时，整棵树的形态发生了极小的变化：**只有 $u$ 和 $v$ 的父子关系反转了**，其余节点的拓扑结构相对不变。

   因此，以 $v$ 为根的新状态 $ans[v]$，可以通过“从 $ans[u]$ 中**剥离** $v$ 原本的贡献，并**加入** $u$ 作为 $v$ 的子树带来的新贡献”在 $O(1)$ 或 $O(\text{度数})$ 的时间内推导出来。

#### 关键性质与难点：操作的可逆性

换根 DP 的顺利实施高度依赖于状态合并操作的**可逆性**。

- **具有逆元的操作（如加法、异或、无取模或安全的乘法）：** 可以直接通过减法或逆运算，从父亲的整体状态中“扣除”当前子节点的贡献。
- **无逆元的操作（如 $\max/\min$）：** 这是高阶比赛中常考的痛点。如果父亲 $u$ 的最大值恰好是由子节点 $v$ 贡献的，当根转移到 $v$ 时，你无法通过简单的减法得到“除了 $v$ 以外 $u$ 的最大值”。
  - **解决方案 1：维护次大值。** 如果最大值来自 $v$，则使用次大值进行转移。
  - **解决方案 2：前后缀优化。** 将 $u$ 的所有子节点的 DP 值排成一个数组，维护该数组的前缀 $\max$ 和后缀 $\max$。在向 $v$ 转移时，直接将 $v$ 对应位置的前缀和后缀合并，完美避开可逆性问题。

### 二、 常见应用场景

换根 DP 的应用场景通常具有明显的特征：**题目在树上，且所求答案与“树根的位置”强相关，要求输出所有节点作为根的答案，或求所有答案的最优值。**

#### 1. 树上距离求和（经典模板）

**场景：** 求树上每个节点到其他所有节点的距离之和。

**状态转移：**

- **DFS 1：** $size[u]$ 表示子树大小，$dp[u]$ 表示 $u$ 的子树内所有节点到 $u$ 的距离和。

  $$dp[u] = \sum_{v \in son(u)} (dp[v] + size[v] \times weight(u, v))$$

- **DFS 2：** 当根从 $u$ 换到 $v$ 时，$v$ 的子树内所有节点到根的距离减少了 $w$，非 $v$ 子树的节点到根的距离增加了 $w$。

  $$ans[v] = ans[u] - size[v] \times w + (N - size[v]) \times w$$

- **特点：** 极度平滑的 $O(1)$ 转移，完美利用了加法的可逆性。

#### 2. 树上最长链 / 最大深度

**场景：** 求以每个节点为根时，树的最大深度（即离每个节点最远的距离）。

**状态转移：**

- **DFS 1：** 求出向下走的最大距离 $down\_max[u]$ 和次大距离 $down\_sec[u]$。
- **DFS 2：** 维护向上走的距离 $up[u]$。对于 $u$ 的子节点 $v$，如果 $v$ 恰好在 $u$ 的最长链上，则 $up[v] = \max(up[u], down\_sec[u]) + w$；否则 $up[v] = \max(up[u], down\_max[u]) + w$。
- **特点：** 典型的“无逆元”处理，通过维护次大值来替代信息的“剥离”。

#### 3. 期望与概率 DP

**场景：** 树上随机游走问题，或者需要计算从每个点出发触发某种状态的概率。

- **特点：** 这类问题往往涉及到繁琐的分数取模和概率推导，换根时需要仔细分离条件概率。通常会结合高斯消元在树上的特殊形式（如将状态表示为 $dp[u] = k \cdot dp[father] + b$），然后利用换根 DP 进行两次扫描解方程。

#### 4. 树上连通块计数与容斥

**场景：** 统计包含每个节点的特定性质的连通块数量或权值和。

- **特点：** 结合前缀/后缀数组优化的重灾区。如果合并操作是多项式乘法或是非互质的模意义下乘法，必须开辟 `vector` 记录父节点的所有子节点前缀和后缀状态，以保证 $O(N)$ 转移。

## 动态过程静态化内外贡献剥离 

**极简题意**

给定一棵 $n$ 个节点的树，初始全白。每次选一个与黑点相邻的白点染黑（首次任意选），得分为此时该点所在白点连通块的大小。求全树染黑的最大总得分。

> **一句话等价**：选定一个根节点，求“**所有节点的子树大小（$siz$）之和**”的最大值。

**思维 Trick (The "Aha!" Moment)**

本题的核心思维跨越在于 **“动态过程静态化”与“贡献等效”**。

1. **打破动态顺序的迷思**：题目描述了一个“一步步扩散染色”的动态过程，很容易让人陷入贪心策略或区间 DP 的误区。
2. **寻找过程中的不变量**：假设我们第一步把点 $R$ 染黑（相当于把 $R$ 拎起来作为树根）。无论接下来按什么顺序染黑其他节点，当你染黑节点 $u$ 时，它与其父节点之间的边必定已经被“阻断”了。因此，$u$ 所在的“白色连通块”，**恰好就是以 $R$ 为根时，以 $u$ 为根的整棵子树**。
3. **终极跃迁**：全树染黑的总得分，其实根本与“后续染色顺序”无关！总得分严格等于：以第一步选择的节点为根时，$\sum siz[i]$。题目瞬间转化为纯粹的**换根 DP**。

**解法一：整体状态转移法（注释掉的代码）**

这种做法的核心思想是“相邻节点间的增量计算”**。它将整棵树看作一个整体，通过寻找相邻两个节点作为根时，全局答案的**差值来进行状态转移。

- **状态定义**：

  - `siz[x]`：以节点 $1$ 为根时，以 $x$ 为根的子树节点数。
  - `sum[x]`：**如果直接以 $x$ 为整棵树的根**，最终获得的总得分（全局答案）。

- **DFS 1（自底向上）**：

  以节点 $1$ 为默认根，计算出所有节点的 `siz`，并求出 `sum[1]`（以节点 $1$ 为起点的基础全局答案）。

- **DFS 2（自顶向下）**：

  当我们把树的根从父节点 $x$ 换到子节点 $y$ 时，整棵树的结构只有两个部分发生了相对深度的改变：

  1. **节点 $y$ 的原本子树**：它离新根更近了，所以这一部分所有节点在计算时，贡献都会减少（具体来说，就是整体少了 $siz[y]$ 的贡献）。
  2. **除了节点 $y$ 子树以外的其余所有节点**：它们离新根更远了，所以贡献都会增加（整体多了 $n - siz[y]$ 的贡献）。

  由此推导出极其优雅的转移方程：

  $$sum[y] = sum[x] - siz[y] + (n - siz[y]) = sum[x] + n - 2 \times siz[y]$$

**总结**：这是最简洁的换根 DP 写法。它的时间复杂度和空间复杂度都极优。**但它的局限性在于：必须要求状态的转移是“可逆的”（比如加减法）**。如果题目要求的是最大值/最小值（例如求树的直径、最长链），这种“加上增量、减去减量”的办法就会失效，因为你无法轻易“减去”一个最大值。

**解法二：拆分内外子树法（你当前启用的代码）**

这种做法的核心思想是“剥离当前节点的上下文”。它不直接维护全局答案，而是严格区分了“子树内部”和“子树外部”的贡献。

- **状态定义**：

  - `siz[x]`：以节点 $1$ 为根时，以 $x$ 为根的子树节点数。

  - `in[x]`：以节点 $1$ 为根时，节点 $x$ 的**子树内部**对其得分的贡献。

  - `out[x]`：以节点 $1$ 为根时，节点 $x$ 的**子树外部**（即它的祖先及兄弟分支）对其得分的贡献。

    最终以 $x$ 为根的全局答案为：$in[x] + out[x]$。

- **DFS 1（自底向上）**：

  计算 `siz` 和 `in`。这里的 `in[x]` 实际上就等同于第一种做法中普通的树形 DP。

- **DFS 2（自顶向下）**：

  在计算 `out[y]`（$y$ 是 $x$ 的子节点）时，我们将外部贡献分为两部分拼凑起来：

  1. **父亲节点 $x$ 的外部贡献**：即 `out[x]`。

  2. **父亲节点 $x$ 的内部贡献中，剔除掉 $y$ 分支的部分**：即 $in[x] - (in[y] + siz[y])$。

     这两部分加起来构成了 $y$ 的“绝对外部”形态，接着因为换根，这部分外部节点作为 $y$ 的新子树，每一层都多了一次整体大小的叠加，因此再加上额外的容量 $(n - siz[y])$。

  由此得出你的方程：

  $$out[y] = in[x] - (in[y] + siz[y]) + out[x] + n - siz[y]$$

**总结**：这是一种更具普适性的换根 DP 范式（也常被称为 In/Out DP 或 Up/Down DP）。虽然方程看起来比第一种长很多，但**它的鲁棒性极强**。当题目涉及的操作不可逆（比如求距离当前节点的最长路径，转移涉及 `max` 函数）时，你只能通过这种剥离出 `out` 数组，结合前后缀最值的方式来做，第一种解法就无能为力了。



## 距离分层与容斥换根

**一句话题意**

给定一棵 $n$ 个节点的树，每个节点带有权值。求对于每个节点，整棵树中距离它不超过 $k$ 的所有节点的权值之和。($n \le 10^5, k \le 20$)

**思维 Trick（关键跳跃点）**

- **维度延展（破局点）：** 单纯的“子树信息”在换根时无法直接转移，因为“距离”在跨越父子边时会 $+1$。突破口在于观察到 $k \le 20$ 极小，必须把“距离”作为 DP 状态的第二维，将状态定义从“节点 $i$ 的信息”延展为“节点 $i$ 在距离 $j$ 限制下的信息”。
- **局部容斥（最易错点）：** 这是换根向下转移（自顶向下）时最核心的思维跳跃。当父节点 $x$ 的全局信息向子节点 $y$ 转移时，$x$ 距离 $j-1$ 的范围内，**天然包含了 $y$ 距离 $j-2$ 的范围**。为了避免这部分“回头路”的权值被计算两次，必须在转移时执行减法：`dp[x][j-1] - f[y][j-2]`。

**编码 Trick（优雅习惯）**

- **前缀和式初始化：** 你的初始化 `f[i][j] = v[i]` 极为巧妙。这使得第二维 $j$ 的语义直接变成了“距离 $\le j$ 的权值和”，而不是“距离恰好等于 $j$”。这省去了在转移时去单独累加子树距离 $0 \dots j$ 的麻烦，规避了大量边界特判。
- **防御性求解（有趣的小细节）：** 最后的输出你写了 `ans = max(ans, dp[i][j])`。由于你的状态已经是距离前缀和，随着距离变大，权值和必然是不降的，所以 `dp[i][k]` 理论上就是最大值。虽然直接输出 `dp[i][k]` 即可，但套一个 `max` 能在状态定义稍有偏差（比如某些距离层未完整累加）时起到意想不到的“防 WA”效果。

**逻辑链条**

1. **明确模型：** 需要求所有节点的全局信息，且可以通过相邻节点推导，锁定**换根 DP**。
2. **状态设计：** 引入距离维度，设计二维状态 `f[u][j]` 表示 $u$ 的子树内，距离 $\le j$ 的权值和。
3. **自底向上：** 第一遍 DFS，利用 `f[x][j] += f[y][j - 1]` 将所有子节点的信息汇聚到父节点。
4. **识别重叠：** 发现父节点向子节点推导全局信息时，子树内部的节点会被当做“外部节点”造成重复计算。
5. **容斥转移：** 第二遍 DFS 换根，通过计算式 `+ dp[x][j - 1] - f[y][j - 2]` 剔除原路返回的贡献，完成全局状态转移。
6. **统计答案：** 遍历所有节点，提取出距离上限为 $k$ 时的最终状态。

### 或者：

**思路 Trick（核心跳跃点）**

- **全树统计的直觉：** 面对“对所有节点求某个结构性质”的问题，且没有修改操作，应当条件反射地想到 **换根 DP（二次扫描法）**。
- **状态的维度展开：** 距离 $K$ 很小（$\le 20$），直接将其作为 DP 的第二维状态。
- **核心 Trick —— 父亲视角的容斥（去重）：** 这是本题最大的思维跳跃。在进行第二次 DFS（自顶向下推导）时，我们要用父亲 $x$ 的信息更新儿子 $y$ 的“子树外贡献”。但父亲 $x$ 在距离 $j-1$ 范围内的节点，包含了儿子 $y$ 在距离 $j-2$ 范围内的节点。为了避免让儿子“重复吃到自己内部的草”，必须做一次容斥减法：$Contribution = x 的总覆盖 - y 的反向覆盖$。
  - 即表达式中的关键项：`in[x][j - 1] - in[y][j - 2]`。

**编码 Trick（优雅实现）**

从你的 AC 代码中，可以看出几个极大地降低了心智负担的编码好习惯：

- **状态前缀和化：** 初始化 `in[i][j] = v[i]`（对于所有 $j \in [0, K]$）。巧妙地将“距离恰好为 $j$”的硬核转移，转化为了“距离 $\le j$”的累加转移，省去了后续再做一次前缀和的麻烦，让转移方程全变为加减法。
- **拆分内外视角（In & Out）：** 相比于你注释掉的混合写法（直接推导全量 `dp`），你最终采用的独立维护 `out` 数组（即子树外距离 $\le j$ 的贡献）的做法极度清晰。`in` 和 `out` 物理隔离，逻辑解耦，最后再相加，是树形 DP 中极佳的工程习惯。

**逻辑链条（一步一动）**

1. **破题切入：** 暴力跑 DFS 是 $O(N^2)$，需要优化到 $O(NK)$，且是对所有节点求值 $\rightarrow$ 确定使用 **换根 DP**。
2. **第一遍扫描（自底向上）：** 维护 `in[x][j]` 表示节点 $x$ 的子树内，距离 $\le j$ 的权值和。
   - *转移：* 儿子距离 $\le j-1$ 的都属于父亲距离 $\le j$ 的，`in[x][j] += in[y][j - 1]`。
3. **第二遍扫描（自顶向下）：** 维护 `out[y][j]` 表示节点 $y$ 的子树外，距离 $\le j$ 的权值和。
4. **容斥处理（最关键一步）：** 节点 $y$ 子树外距离 $\le j$ 的点，等于 **父亲 $x$ 子树外距离 $\le j-1$ 的点** 加上 **父亲 $x$ 子树内距离 $\le j-1$ 但剔除掉从 $y$ 走上来的点**。
   - *转移：* `out[y][j] = out[x][j - 1] + (in[x][j - 1] - in[y][j - 2])`。
5. **边界收束：** 注意处理 $j=0$ 和 $j=1$ 的边界（父亲本身），避免数组越界。
6. **统计答案：** 对于任意节点 $i$，其距离 $\le K$ 的总量即为内部与外部的拼图补全：$Ans_i = in[i][K] + out[i][K]$。





## 流量剥离与换根 DP

**一句话题意**

给定一棵带有边权（容量）的无根树。求选定哪个节点作为源点时，流向所有叶子节点（终端）的流量总和最大，求出这个最大流量。

**思维 Trick (关键跳跃点)**

- **跳跃一：从“网络流”到“树形 DP”的降维。** 看到“容量”、“源点流向多点”，直觉容易往最大流想。但在**树形结构**中，任意两点间路径唯一，流量不具备复杂网络中的“增广”和“分流”特性。源点到某子树的流量仅仅受限于**当前边权**和**子树内部的叶子容量和**，因此可以完美降维成 $\min(\text{边权}, \text{子树流量})$ 的树形 DP。
- **跳跃二：换根时的“流量剥离”（最难点）。** 在做第二次自顶向下的 DFS 时，父节点 $x$ 的全局最大流量 `dp[x]` 是已知的。当根从 $x$ 转移到 $y$ 时，$x$ 相对于 $y$ 变成了一棵“子树”。此时 $x$ 能提供给 $y$ 的流量，等于 $x$ 的全局流量剥离（减去）原本流向 $y$ 的那部分流量，然后再受限于边权 $w$。
- **跳跃三：叶子节点的分类讨论。** 原树的叶子节点在换根过程中角色会发生突变。如果 $x$ 是叶子（度数为 $1$），剥离流量时不能用常规方程；如果 $y$ 是叶子，它向下没有流量，向上却可以接收流量。理清度数为 $1$ 时的边界条件是这题 AC 的关键。

**编码 Trick (优雅习惯)**

- **度数判断替代额外数组：** 你代码中直接使用 `adj[x].size() == 1` 来判断叶子节点，极其优雅。这省去了一开始建树时维护 `in_degree` 或 `out_degree` 数组的麻烦，且在树形结构中绝对安全。
- **Lambda 闭包实现 DFS：** 你的 `auto dfs1 = [&](auto &&self, int x, int p)` 写法将 DFS 函数局域化，不仅避免了全局变量污染，还省去了传递辅助状态的麻烦，这是非常现代且能降低心智负担的工程习惯。

**逻辑链条**

1. **模型转换**：将全局网络流问题，降维成局部受限的树形 DP 问题。
2. **自底向上 (dfs1)**：求出 `v[x]`，即以 $x$ 为局部根时，流向其**子树内**所有叶子的最大流量。
3. **状态推导**：明确全局状态 `dp[y]` = 子树内部流量 `v[y]` + 父节点反向流过来的流量。
4. **流量剥离 (容斥)**：计算父节点反向流量时，用全局 `dp[x]` 减去原本流向 $y$ 的局部流量。
5. **自顶向下 (dfs2)**：通过换根 DP，结合度数特判（处理叶子边界），将父节点的全局状态推导给所有子节点。
6. **统计答案**：遍历 `dp` 数组，取最大值。



## 最大合法切除块与换根 DP

**极简题意**

给定一棵 $n$ 个节点的树。你最多可以进行一次操作（删去一条边并加上一条边，保持树的形态）。对于树上的每一个节点，判断是否能在操作后使其成为这棵树的**重心**（即删除该节点后，没有任何连通块的大小 $> \lfloor n/2 \rfloor$）。

**思路 Trick（思维跳跃点）**

**跳跃一：唯一超标连通块（性质挖掘）**

如果一个节点目前不是重心，那么在它的所有相邻连通块（各个子树，以及向上的父节点连通块）中，**有且仅有一个**连通块的大小 $> \lfloor \frac{n}{2} \rfloor$。这意味着我们唯一的操作机会，必须精准用在这个“超标”的连通块上。

**跳跃二：贪心切除策略（题意转化）**

要在超标连通块中切掉一棵子树挂到当前节点上。这棵被切下来的子树必须满足两个条件：

1. **自身合法**：它的大小本身必须 $\le \lfloor \frac{n}{2} \rfloor$，否则挂过来后会成为新的超标连通块。

2. **尽可能大**：为了让原来超标的连通块“瘦身”到及格线以下，切走的部分必须越大越好。

   至此，题目转化为：求每个连通块内部，大小 $\le \lfloor \frac{n}{2} \rfloor$ 的**最大子树**。

**跳跃三：空间视角的内外解耦（状态定义）**

对于节点 $x$，连通块分为两类：向下的各个子树、向上的父节点连通块。因此将“寻找最大合法子树”解耦为：

- **内部**：`mx1[x]`，以 $x$ 为根的子树内，合法的最大子树。
- **外部**：`out[x]`，$x$ 所在的子树外部，合法的最大子树。

**编码 Trick（优雅实现的习惯）**

1. **最大值与次大值维护（换根DP标配）：** 在自顶向下传递信息时，父节点需要把信息传递给子节点。但如果父节点的“最大值”刚好来源于这个子节点，就会产生冲突。你的代码中非常标准地维护了 `mx1`（最大值）、`mx2`（次大值）以及 `chose`（最大值的来源）。这样在向下传递时，只需一个 `if(chose[x] == y)` 即可在 $O(1)$ 时间内完成分支，避免了繁琐的重新遍历，极大地降低了思维负担和出错率。

2. **现代 C++ 的 Lambda 递归（封装之美）：**

   使用 `auto dfs = [&](auto &&self, int x)`。这种写法的好处在于：避免了将 `siz`, `mx1`, `mx2` 等大量辅助数组开成全局变量导致命名污染；同时利用捕获列表 `[&]`，不需要在函数签名里传来传去，让整个 `solve()` 函数逻辑高度内聚，这在多测题目中能有效避免清空数组时的遗漏问题（你的代码中每次 `solve` 重新 `vector` 声明就是绝佳习惯）。

**逻辑链条（一句话思维流）**

1. **明确目标**：节点能成为重心 $\iff$ 移除它后，周围所有连通块大小均 $\le \lfloor n/2 \rfloor$。
2. **定位痛点**：若该节点不满足条件，必然存在**唯一**一个大小 $> \lfloor n/2 \rfloor$ 的连通块。
3. **贪心策略**：只需从该超大连通块中，减去一个大小 $\le \lfloor n/2 \rfloor$ 的**最大合法子树**，检查剩余大小是否 $\le \lfloor n/2 \rfloor$ 即可。
4. **状态定义**：我们需要快速知道每个节点“向下的子树中”以及“向上的父节点方向中”的最大合法子树大小（`mx1` 与 `out`）。
5. **第一遍 DFS（自底向上）**：统计基础 `siz`，并计算出每个节点子树内部的最大合法子树 `mx1` 和次大合法子树 `mx2`。
6. **第二遍 DFS（自顶向下）**：利用 `mx1` 和 `mx2` 进行换根，计算出每个节点向上（外部）的最大合法子树大小 `out`。
7. **统一校验**：遍历所有节点，分别检查其子节点方向和父节点方向的连通块大小；若超标，则减去对应的 `mx1[y]` 或 `out[x]`，判断是否达标，输出答案。



## 虚树遍历与最长链剥离

**一句话题意**

给定一棵带权树和 **K** 个目标点。求从树上任意一个节点出发，遍历所有 **K** 个目标点（不要求回到起点）所需的最短总时间。

**思维 Trick (关键跳跃点)**

- **跳跃一：从“游走”到“虚树”的转化。** 题目要求经过特定的 **K** 个点，在树上，包含这 **K** 个点及起点的最小连通子图必然是一棵树（可以理解为这 **K** 个点构成的虚树）。
- **跳跃二：闭环折返与单向终点（题意剥离）。** 如果要求最终**回到起点**，那么虚树上的每一条边都必然被经过且仅被经过两次（一来一回），总时间固定为 **2 \* 虚树边权和**。
- **跳跃三：贪心减枝。** 题目**不要求**回到起点。这意味着，我们最后走向的那一个目标点，其对应的路径不需要折返。为了让总时间最小，我们应该把从起点出发到所有目标点中，**距离最长的那条路径**留到最后走。
  - **核心等式**：最终答案 = **2 \* 虚树边权和 - 起点到目标点的最长距离**。
  - 至此，问题被完美解耦为两个经典的树形 DP 独立子问题：求包含特定点的边权和、求树上单源最长链。

**编码 Trick (优雅习惯)**

- **人数计数作为天然的 Boolean 标志（极简合法性判断）：**

  在处理“子树内是否包含目标点”时，你直接利用了 `people[y]` （子树内的目标点个数）。

  - 向下转移时：`if(people[y])` 完美判断了是否需要走向该子树。
  - 向上换根时：`if(m - people[y])` （全局目标数减去子树目标数）完美判断了当前节点 $y$ 的**外部**是否存在目标点，决定了是否需要向外走。这种用计数代替额外 `bool` 数组的写法，极大地降低了代码的冗余度。

- **最大/次大值规避法（换根经典套路）：**

  在 `dfs2` 推导外部最长链 `outmx[y]` 时，你同时维护了 `inmx1`, `inmx2`, `chose`。转移时一个简单的 `if(chose[x] == y)` 分支，完美避开了“父节点的最长链刚好是当前子树贡献的”这种路径重叠问题。

- **Cost 状态的直接累加：**

  计算边权和时，你的 `incost` 和 `outcost` 直接维护了双倍边权（`w * 2`）。这让最终的答案合并公式 `incost[i] + outcost[i] - max(inmx1[i], outmx[i])` 显得极其干净，没有任何临时乘 2 的心智负担。

**逻辑链条**

1. **思维解耦**：将最短游走问题转化为“双倍虚树边权和”减去“单源最大距离”。
2. **定义内部状态**：通过 `dfs1`，自底向上统计每个子树内的目标点数量 `people`、双倍边权和 `incost`，以及到目标点的最长链 `inmx1` 和次长链 `inmx2`。
3. **定义外部状态**：通过 `dfs2`（换根），利用父节点的全局信息，自顶向下推导出当前节点外部的双倍边权和 `outcost`，以及向外的最长链 `outmx`。
4. **容斥转移**：在 `dfs2` 中，严格根据 `people` 数组判断内外方向是否“值得去”（是否有目标点），并利用次大值规避路径重叠。
5. **全局收网**：遍历所有节点，按核心等式直接拼装局部与外部状态，以 **O(N)** 的复杂度得出每个点的最优解。
