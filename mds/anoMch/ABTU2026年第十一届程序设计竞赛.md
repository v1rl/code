## E 值域因数枚举优化 LCM

------

**极简题意摘要**

给定长度为 $N$ 的序列 $a$（元素值域 $\le V$），对每个下标 $i \in [2, N]$，动态求前缀中的最小最小公倍数：

$$\min_{1 \le j < i} \text{lcm}(a_j, a_i)$$

**限制**：$N, V \le 2 \times 10^5$，需实现接近线性或带小常数对数的复杂度。

------

**思维 Trick (关键转换与贪心注意力)**

1. **核心公式拆解（将双变量去耦合）**：

   求 $\text{lcm}(a_j, a_i) = \frac{a_j \times a_i}{\gcd(a_j, a_i)}$。直接在前面找 $a_j$ 极难维护，因为 $\gcd$ 是由两数共同决定的。

   **关键跳跃**：令 $g = \gcd(a_j, a_i)$，则 $g$ 必然同时是 $a_j$ 和 $a_i$ 的因数。原式可重写为：

   $$\text{lcm}(a_j, a_i) = a_i \times \left( \frac{a_j}{g} \right)$$

   对于固定的当前数 $a_i$，只要枚举它所有的因数 $g$，问题就转化为：**在历史出现过的数中，找到包含因数 $g$ 的最小的 $a_j$**。

2. **状态桶的定义与贪心维护**：

   由于值域 $V$ 很小，设立全局桶 `mn[g]` 表示“当前前缀中，含有因数 $g$ 的最小元素值”。

   对于当前 $a_i$ 的每个因数 $g$，候选答案即为 $\frac{a_i \times \text{mn}[g]}{g}$，取所有因数贡献的最小值即可。

3. **边查询边更新（消去时序限制）**：

   由于题目要求 $j < i$，我们只需在处理第 $i$ 个数时，先用当前的 `mn` 数组查询答案，随后再用 $a_i$ 去更新其所有因数 $g$ 的桶 (`mn[g] = min(mn[g], x)`)。这完美契合了前缀查询的要求。

------

**编码 Trick (优雅实现方式)**

1. **DFS 组合质因数生成全因数**：

   如果单次用 $O(\sqrt{a_i})$ 去试除找因数，耗时较长且不够优雅。代码中先通过线性筛求出 `minp`（最小质因数），$O(\log V)$ 对 $a_i$ 完成质因数分解存入 `ps` 数组（形如 $\{p, \text{cnt}\}$），再利用 `dfs` 组合生成所有因数。这样只访问真正的因数，常数极小，且逻辑十分清晰。



## G **位运算自同态与虚树区间剪枝**

------

**一句话题意**

给定一棵 $n$ 层（$n \le 60$）的满二叉树，每层对应一个操作数 $s_i$。根节点权值为 $s_1$。对于第 $i$ 层的节点权值 $W$，其左儿子权值为 $W \ \& \ s_{i+1}$，右儿子权值为 $W \ | \ s_{i+1}$。

支持两种操作：

1. 修改单层的控制参数：$s_i \leftarrow s_i \oplus x$。
2. 查询叶子节点（共 $2^{n-1}$ 个）在编号区间 $[l, r]$ 内所有权值的**异或和**。

- **核心特征**：树的深度极大（$n \le 60$），叶子节点多达 $2^{59}$ 无法显式建树。运算混合了 `&`、`|` 和 $\oplus$。

------

**思维 Trick (关键跳跃)**

本题的核心跳跃在于“按位独立性（自同态坍缩）”**与**“子树完全覆盖下的奇偶抵消”。

- **Trick 1：布尔位运算的独立映射与坍缩（绝对的注意力跳跃）**

  通常看到混合的位运算，第一反应是拆位。但本题有一个极其惊艳的局部代数性质：

  对于满二叉树中的任意一个非叶子节点（处于第 $i$ 层，权值为 $W$），它的左儿子是 $W \ \& \ s_{i+1}$，右儿子是 $W \ | \ s_{i+1}$。

  如果我们要计算它**两个儿子的异或和**：

  $$(W \ \& \ s_{i+1}) \oplus (W \ | \ s_{i+1})$$

  根据布尔代数恒等式 $A \oplus B = (A \ \& \ \neg B) \ | \ (\neg A \ \& \ B)$，或者直接画真值表拆位观察：

  - 当 $s_{i+1}$ 的某一位为 `0` 时：左儿子该位变为 `0`，右儿子该位保持 $W$ 的原值。两者异或结果为 $W$ 的原位。
  - 当 $s_{i+1}$ 的某一位为 `1` 时：左儿子该位保持 $W$ 的原值，右儿子该位变为 `1`。两者异或结果仍然相当于把 $W$ 的原位取反再与 `1` 异或，等价于 $W \oplus s_{i+1}$ 的特定位推演。

  **终极化简恒等式**：

  $$(W \ \& \ s_{i+1}) \oplus (W \ | \ s_{i+1}) = W \oplus s_{i+1}$$

  这意味着，一个父节点向下分裂成两个儿子后，其两个儿子的权值异或和，**完全等价于**父节点权值直接异或上下一层的参数！

- **Trick 2：完全覆盖区间的 $O(1)$ 剪枝（满二叉树的对称性抵消）**

  由于我们查询的是区间叶子节点的异或和，当线段树递归查询到一个节点 $u$ 时，如果当前节点控制的叶子区间 $[L, R]$ **完全包含**在查询区间 $[l, r]$ 内：

  - 如果 $u$ 就是最后一层（第 $n$ 层），贡献直接是当前推演出的 $W$。

  - 如果 $u$ 不是最后一层，它的整棵子树的叶子都会被选中。由于这是一棵高度对称的满二叉树，每一层分裂都会产生成对的左右儿子。利用 **Trick 1** 的结论，层层向下折叠合并，最终整棵子树所有叶子的异或和直接坍缩为：

    $$W \oplus s_{i+1} \oplus s_{i+1} \dots \text{（根据深度奇偶性抵消）}$$

    实际上，只要往下走超过一层，成对的节点就会以 2 的幂次方倍数复制复制。在异或运算下，**任何大小为偶数的相同集合异或和均为 0**。

    因此，完全覆盖子树的贡献仅在向下看**恰好一层**时保留有效异或值：

    $$\text{SubtreeXor}(u) = W \oplus s_{i+1}$$

    直接 $O(1)$ 返回！这使得原本需要遍历 $2^{60}$ 的搜索树，瞬间被剪枝成了标准的线段树区间查询，单次查询访问的节点数严格控制在 $O(n)$ 级别。

------

**编码 Trick (优雅实现)**

你的 AC 代码不仅完美贴合了数学推演，还利用了非常高级的动态计算范式：

- **编码 Trick 1：隐式满二叉树（无指针线段树递归）**

  面对 $2^{60}$ 的树，你完全抛弃了常规的数组建树或动态开点，直接利用递归函数传参 `(p, l, r)` 隐式表达线段树节点。通过 `val` 参数向下实时传递位运算状态：

  ```cpp
  return self(self, p + 1, l, mid, x, y, val & a[p + 1]) ^ 
         self(self, p + 1, mid + 1, r, x, y, val | a[p + 1]);
  ```

  左递归传 `&`，右递归传 `|`，将建树、修改、下推完全融为一体，达到了空间复杂度 $O(N)$（仅存每层参数）的极致表现。



## B **降序插入与奇偶前缀分割 DP**

------

**一句话题意**

给定长为 $n$ 的序列 $p$（权值互不相同），寻找好位置数量 $\ge m$ 的排列个数，答案对 $998244353$ 取模。

- **好位置的定义**：对于排列中的位置 $i$，若其左侧存在一个位置 $j < i$ 满足二者**奇偶性不同**且**权值 $p_j > p_i$**，则 $i$ 为好位置。
- **核心特征**：好位置的判定依赖于左侧**是否存在**（而非具体数量）比当前元素大且奇偶互异的数。

------

**思维 Trick (关键跳跃：从指数级状压到多维连续段插入)**

如果按原序列的从左到右去依次填数，为了判定当前位置 $i$ 是否合法，我们需要知道它左侧填了哪些具体的数值以及它们的奇偶分布，这必然导致 $O(2^n)$ 级别的全集状态压缩。本题最核心的思维升华在于**重塑排列生成视角**。

**Trick 1：视角切换 —— 降序插入法消解大小关系（无后效性构建）**

我们将原数组 $p$ 降序排列得到数组 $a$（$a_1 > a_2 > \dots > a_n$），并按此顺序依次将元素**插入**到当前已形成的相对序列中。

当我们要插入第 $i+1$ 个元素 $a_{i+1}$ 时，当前排列中已经存在 $i$ 个数。**极其美妙的局部性质**：

因为我们是按降序填数，所以**当前序列中现存的这 $i$ 个数，每一个都严格大于 $a_{i+1}$**。

这意味着，只要把 $a_{i+1}$ 插入到任意一个**与它奇偶性不同**的数的右侧，它立刻就能成为一个合法的好位置！

**Trick 2：前缀阻断与“第一个异偶位”状态降维（降维打击）**

假设当前准备填入 $a_{i+1}$，当前序列的相对顺序为 $b_1, b_2, \dots, b_i$。我们要把它插在某个空隙（共 $i+1$ 个候选插槽：最左侧、各元素右侧）。

- 插入在 $b_k$ 的右侧时，$a_{i+1}$ 左侧的元素集合就是 $\{b_1, \dots, b_k\}$。
- 只要这个前缀集合中存在至少一个数与 $a_{i+1}$ 奇偶不同，$a_{i+1}$ 就是好位置。

**关键跳跃**：为了区分哪些插槽能提供好位置，我们完全不需要记录序列的具体形态，**只需要知道从左往右扫描时，第一个与首位元素（$b_1$）奇偶性不同的数出现在哪个下标 $j$**。

- 序列首位元素的奇偶性记为 $op \in \{0, 1\}$。
- 序列中第一个奇偶性为 $op \oplus 1$ 的数出现在下标 $j$（若全序列同色则认为 $j=i+1$ 对应最右侧边界外）。
- **插槽分界线**：
  - 前 $j-1$ 个数全都是奇偶性为 $op$ 的数。插入在它们左侧或中间（共 $j$ 个插槽），新元素左侧只存在同为 $op$ 的数。
  - 插入在第 $j$ 个数右侧及更往后的位置（共 $i+1-j$ 个插槽），新元素左侧必然包含了第 $j$ 个数（即异偶数），从而被激活为好位置。

**Trick 3：同色与异色转移推演**

基于上述抽象，状态定型为 $dp[op][j][k]$ 表示当前已插入序列首位奇偶为 $op$，第一个异偶位为 $j$，且已累积 $k$ 个好位置的方案数。考虑填入 $a_{i+1}$：

1. **新元素与首位同色（$a_{i+1} \equiv op \pmod 2$）**：
   - 插入在前 $j$ 个插槽：不会改变首位颜色，也不会提供新的异偶位，且新元素无法与左侧同色的前缀产生贡献。转移至 $dp[op][j+1][k]$（插槽数增加导致异偶下标右移）。
   - 插入在后 $i+1-j$ 个插槽：左侧存在异偶数，新元素成为好位置，且不会改变首位和第一个异偶位。转移至 $dp[op][j][k+1]$。
2. **新元素与首位异色（$a_{i+1} \not\equiv op \pmod 2$）**：
   - 插入在**最左侧（第 1 个插槽）**：新元素抢占首位，首位颜色反转为 $op \oplus 1$。原先的首位（颜色 $op$）退居第 2 位，立刻成为新的“第一个异偶位”！新元素无左侧邻居，无贡献。转移至 $dp[op \oplus 1][2][k]$。
   - 插入在第 $2 \sim j$ 个插槽：左侧全为 $op$，新元素异色，成为好位置。且它成为了序列中**最靠左的异偶数**，更新异偶下标。转移至 $dp[op][\text{插槽位置}][k+1]$。
   - 插入在后 $i+1-j$ 个插槽：左侧存在同色和异色，新元素异色且左侧包含原首位 $op$，成为好位置。不影响首位和最左异偶位。转移至 $dp[op][j][k+1]$。

------

**编码 Trick (优雅实现)**

你的 AC 代码中运用了极其精炼的刷表与后缀和优化，将本该分类繁琐的内部循环压缩到了极致：

- **编码 Trick 1：利用 `std::move` 实现无感知滚动数组**

  在处理阶段式 DP 时，手写三维或四维滚动数组容易下标混淆。你直接在循环内声明局部的 `ndp`，并在轮次末尾执行 `dp = move(ndp)`。这不仅在语义上保持了清晰的阶段独立性，且利用底层指针置换达到了 $O(1)$ 的极致空间复用。

- **编码 Trick 2：利用后缀和优化异色前缀转移（将 $O(N^4)$ 压至 $O(N^3)$）**

  在异色转移中，插入在第 $2 \sim j$ 个插槽时，原状态 $dp[op][j][k]$ 可以向所有下标小于 $j$ 的新异偶下标辐射。如果暴力枚举落点会多出一维开销。

  你巧妙地采用了**倒序循环配合实时后缀和累加**：

  ```cpp
  chadd(suf, dp[op][j][k]);
  chadd(ndp[op][j][k + 1], suf);
  ```

  边倒推边累加残留状态，一次遍历完成了所有前缀落点的批量分发，是极佳的代数结构优化范式。

- **编码 Trick 3：封装带模加法引用函数**

  在取模密集的内层循环中，使用 `ans = (ans + val) % mod` 会引发极慢的 CPU 除法指令。封装 `chadd(int &x, int y)` 利用减法代替取模：

  ```cpp
  void chadd(int &x, int y) { x += y; if(x >= mod) x -= mod; }
  ```

  常数极低，大幅提升了多维状态转移的执行效率。
