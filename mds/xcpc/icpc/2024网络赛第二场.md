## C 增量贡献拆解与在线 KMP 失配 DP

**题目极简总结**

**题意**：维护一个初始为空的字符串 $S$。每次在末尾追加一个字符 $S_i$（强制在线），同时给出 $A_i, B_i$。每次操作后需要输出 $\sum_{i=1}^n \sum_{j=i}^{i+z_i-1} A_j \times B_i$，其中 $z_i$ 是后缀 $S[i \dots n]$ 与前缀 $S[1 \dots n]$ 的最长公共前缀（LCP）长度。

**思路 Trick (Key Observations)**

这道题最核心的难点在于：公式里有 $z_i$，看起来像是要求 Z-函数（扩展 KMP），但 Z-函数很难高效地在线维护。破局点在于**不要去求 $z_i$，而是去看第 $n$ 步对答案产生了什么增量。**

1. **增量法与贡献拆解 (数学跳跃)**
   - **痛点**：每次更新都要计算所有后缀的 LCP，复杂度爆炸。
   - **跳跃**：考察当加入第 $n$ 个字符 $S_n$ 时，内层求和 $\sum_{j=i}^{i+z_i-1} A_j$ 发生了什么变化。
   - **推演**：如果后缀 $S[i \dots n]$ 还能和前缀匹配，说明它的 LCP 从 $n-i$ 涨到了 $n-i+1$。此时，内层循环的上限增加了 $1$，恰好把 $A_n$ 给纳入了求和范围！如果它失配了，它的 LCP 就永远定格了，以后再加字符也不会把 $A_n$ 加进去。
   - **结论**：第 $n$ 步时，答案的增量 $\Delta ans = A_n \times \sum B_i$ （满足条件：后缀 $i$ 目前依然和前缀完全匹配）。我们将复杂的 LCP 问题，降维成了**维护当前处于“存活”状态的匹配后缀的 $B_i$ 之和**！
2. **有效后缀与 KMP Border 的等价映射 (字符串跳跃)**
   - **痛点**：如何在线维护哪些后缀“存活”、哪些“死亡”（失配）？
   - **跳跃**：一个后缀 $S[i \dots n]$ 等于前缀 $S[1 \dots n-i+1]$，这在字符串理论中叫做 **Border**！
   - **结论**：存活的后缀集合，恰好就是当前字符串的所有 Border。加入新字符 $S_n$ 时，我们只需要找出哪些 Border 无法扩展（即 $S_{L+1} \neq S_n$），从总和中减去它们的 $B_i$ 即可。这就完美转化为了 KMP 算法。

**编码 Trick (Coding Elegance)**

你代码中最精彩的部分是引入了 `fails[i]` 数组。这是一个神来之笔，相当于在 KMP 自动机上做了一次 DP。

- **痛点**：标准的 KMP `while(j && s[i] != s[j]) j = ne[j-1]` 循环，确实能跳过失配的 Border，**但它只能找出比最终存活的 Border 更长的那些失配 Border**。如果存在比最终存活 Border 更短的 Border 也失配了，标准的 KMP 循环是不会遍历到它们的！

- **编码 Trick：KMP 失配树上的状态继承 (DP)**

  你的代码中：

  ```cpp
  if(s[i] == s[j]) {
      for(auto x : fails[j]) fails[i].emplace_back(x);
  }
  ```

  - **原理解释**：`fails[i]` 记录的是“试图与 $S_i$ 匹配时，所有断裂的 Border 长度”。当 `s[i] == s[j]` 匹配成功时，比 $j$ 更短的那些失配 Border 去哪找？它们恰好就是“试图与 $S_j$ 匹配时断裂的 Border”！所以直接继承 `fails[j]`。
  - **优雅之处**：通过显式地维护 `fails` 数组，你用均摊 $O(1)$ 的状态转移，极其精准地捕捉到了**所有**在当前字符死亡的 Border，随后统一执行 `pre -= b[i - x]`，逻辑闭环，无需任何复杂的数据结构。

### 逻辑链条 (The Logic Chain)

1. **视角反转**：不求全局的 LCP，改求第 $n$ 步加入时 $A_n$ 对全局答案的增量贡献。
2. **提炼系数**：发现 $A_n$ 的系数就是“当前依然与前缀匹配的所有后缀的 $B_i$ 之和”，记为 `pre`。
3. **转化 Border**：将“匹配的后缀”转化为“当前前缀的 Border”，纳入 KMP 算法体系。
4. **增量维护 `pre`**：每读入一个字符，无条件将它的 $B$ 计入 `pre`（因为它自己构成长度为 1 的 Border），并剔除那些在这一步失配的 Border 的 $B_i$。
5. **精准剔除（失配 DP）**：利用 `fails[i]` 数组，在 KMP 跳跃和匹配时，继承并记录所有失配的 Border 长度，实现快速剔除，完成状态流转。



## E 奇偶分层图 / 威胁时间戳

**极简题意**

一张 $n$ 点 $m$ 边的无向图，玩家从起点 $1$ 逃往终点 $n$。图上有 $k$ 个机器人与玩家**同步移动**，机器人可随意走动并能通过“原路折返”消除路径记录（变相允许在原地或小范围内耗时间）。如果机器人不折返的最短行进距离超过 $d$ 则自毁。

**目标**：求出一条玩家到终点的最短路径，保证在任何时刻，玩家所在节点都没有存活的机器人。输出最短步数及路径。

**思路 Trick (思维跳跃点)**

1. **“原路折返”的本质 = 同奇偶性自由拖延**

   这是题意中最核心的包装。机器人可以原路折返意味着：只要机器人能在 $t$ 步内到达点 $v$（且 $t \le d$ 防止自毁），那么对于任何 $T \ge t$ 且 **$T$ 与 $t$ 同奇偶** 的时刻，机器人都可以通过在附近“反复横跳”在时刻 $T$ 准时出现在点 $v$。

2. **变“躲避具体实体”为“避开危险时间戳”**

   不需要考虑每个机器人具体在哪。我们将所有机器人视为一种“污染源”，直接预处理出**任何**机器人到达某个点 $v$ 的**最早偶数时刻**和**最早奇数时刻**。只要玩家到达 $v$ 的时间严格早于这个“最早污染时间”，就是安全的。

3. **自毁参数 $d$ 的转化 = BFS的最大深度截断**

   题意中复杂的“记录路径长度超过 $d$ 则自毁”，在最短路的视角下，其实就是指机器人的有效威胁半径只有 $d$。在 BFS 预处理机器人到达时间时，一旦当前距离达到 $d$ 就停止扩展即可。

**编码 Trick (优雅的代码习惯)**

从你的 AC 代码中可以提取出以下能够大幅降低编码心智负担的技巧：

1. **位运算切换奇偶状态 (`c ^ 1`)**

   极其优雅的状态转移。不使用繁琐的 `if (c == 0) ... else ...`，而是直接将奇偶性作为状态的第二维度，利用 `^ 1` 自动翻转，这在图论的分层图（Layered Graph）中是绝佳的习惯。

2. **多源 BFS 替代单源汇合**

   处理 $k$ 个机器人的最短路时，没有写一个循环跑 $k$ 次 BFS，而是在初始化时将所有机器人的起点直接 `push` 进同一个队列。这让多个污染源的扩散在一次 BFS 内并行完成，代码短且时间复杂度严格保证为 $O(N+M)$。

3. **统一的前驱记录方式 (`pre[c ^ 1][y] = x`)**

   在求最短路的同时利用 `pre` 数组记录状态（不仅记录前驱节点，还隐含了奇偶性的逆推，配合最后的 `t ^= 1` 回溯），让路径还原变得非常清晰。

**思路逻辑链条**

1. **识别特征**：同步移动 + 图上追逐问题 $\rightarrow$ 必须考虑步数的奇偶性。
2. **拆解限制**：机器人可折返且有自毁半径 $d$ $\rightarrow$ 机器人的威胁区域是距离起点 $\le d$ 的所有点，且威胁一旦到达便在同奇偶时刻永久存在。
3. **预处理威胁**：建立奇偶两层图，利用多源 BFS 求出全图每个节点在奇数/偶数步被机器人覆盖的**最小步数** `dmn[0/1][x]`。
4. **玩家寻路**：玩家同样在奇偶两层图上跑单源 BFS，状态转移的合法条件仅为：玩家到达点 $y$ 的时间 $dist + 1$ 必须**严格小于** `dmn[c ^ 1][y]`。
5. **回溯输出**：比较终点 $n$ 在奇数和偶数状态下的距离，选较小者的状态逆序顺藤摸瓜找回全路径。



## G 更相减损转欧几里得加速

**题目极简总结**

**题意**：Alice 和 Bob 初始各有 $x, y$ 个筹码，单回合两人各有固定胜率，平局则重开。单回合中，若胜者筹码 $\ge$ 败者，则胜者直接赢得**整场游戏**；否则，败者扣除等同于“胜者当前筹码量”的筹码，游戏继续。求 Alice 赢得整场游戏的概率。

**思路 Trick (Key Observations)**

冲击金牌的过程中，这类题目的难点往往在于如何跨越“模拟”的思维定势，找到状态转移的“捷径”。本题有两个关键跳跃：

1. **概率归一化（消除自环）**
   - **痛点**：存在平局，导致状态 $(x, y)$ 可能转移到自身 $(x, y)$，形成无限递归的自环。
   - **跳跃**：在已知游戏一定会结束的前提下，平局是**无效对局**。我们直接将其从样本空间中剔除，重新定义单局胜率：$P_A = \frac{p_0}{p_0 + p_1}$， $P_B = \frac{p_1}{p_0 + p_1}$。这样 $P_A + P_B = 1$，彻底消除了平局。
2. **状态跃迁：将“减法模拟”化归为“取模加速” (核心 Trick)**
   - **痛点**：如果 $x = 10^9, y = 1$，每次回合 Bob 赢，状态变成 $(x-1, y)$。如果一步步减，必定 TLE。
   - **跳跃**：仔细观察游戏规则：当 $x \ge y$ 时，如果是 Alice 赢，游戏直接结束（Alice 胜利）；只有当 Bob 赢时，状态才会变成 $(x-y, y)$。
   - 这不就是求最大公约数（GCD）时的**更相减损术**吗！
   - 为了加速，我们可以一次性计算出状态发生“反转”（即 $x < y$）需要连续减去多少次 $y$。次数 $k = \lfloor x/y \rfloor$。
   - 在这连续的 $k$ 次交锋中，Bob 必须**全胜**（概率为 $P_B^k$）才能把状态推演到 $(x \bmod y, y)$。只要这 $k$ 局中 Alice 赢下**任意一局**，Alice 就直接赢下整场比赛。这完美契合了欧几里得算法（辗转相除法）的 $O(\log N)$ 复杂度！

**编码 Trick (Coding Elegance)**

**物理意义**：Alice 在前 $k$ 局中截杀获胜的概率，实际上等价于 **1 减去 Bob 连续赢 $k$ 局的概率**！

`int res = (1 - qmi(b, k) + mod) % mod;`

这不仅让思维更直观，还省去了一次 $O(\log M)$ 的快速幂求逆元，大幅降低了常数。

**逻辑链条 (The Logic Chain)**

解决本题的思考步骤，浓缩为以下五步：

1. **消除平局**：重定义 $P_A$ 和 $P_B$，使得 $P_A + P_B = 1$，消除状态机的自环。
2. **规则映射**：发现状态转移 $(x, y) \to (x-y, y)$ 完美对应欧几里得算法的减法形式。
3. **分块加速**：将连续减法合并为取模操作，求出状态翻转所需的连续失败次数 $k = \lfloor x/y \rfloor$。
4. **概率推演**：利用 $1 - P_B^k$ 算出当前阶段直接终结比赛的概率，加上 $P_B^k \times P(x \bmod y, y)$ 的后续递归概率。
5. **递归边界**：当某一方筹码变为 $0$ 时（即 $x \bmod y = 0$），由于题目保证初始全为正，此时直接返回胜负结果即可（代码中的 `!x` 返回 $0$，`!y` 返回 $1$）。



## I 基准态偏移与二进制翻转构造

**题目极简总结**

**题意**：给定非负整数 $n < 2^{30}$，求其在系数 $a_i \in \{-1, 0, 1\}$ 下的二进制展开 $n = \sum_{i=0}^{31} a_i 2^i$。

**限制**：绝对不能出现相邻的两个 $0$（即 $a_i^2 + a_{i+1}^2 \neq 0$）。若无法构造输出 `NO`。

**思路 Trick (Key Observations)**

这道题最容易让人陷入“从低位到高位贪心填数、分类讨论进位”的泥潭（往往要写几十行又臭又长的判断）。你的 AC 代码之所以如此简短，是因为完成了两个极其跳跃的神仙级 Observation：

1. **同余性质洞察（判无解）**

   - **痛点**：什么情况下会无解？

   - **跳跃**：考察 $n$ 模 4 的余数。$n = a_0 + 2a_1 + 4a_2 + \dots \equiv a_0 + 2a_1 \pmod 4$。

     如果 $n \equiv 0 \pmod 4$，意味着 $a_0 + 2a_1 \equiv 0 \pmod 4$。

     因为 $a_0 \in \{-1,0,1\}$，为了让和是偶数，$a_0$ 只能取 $0$。此时 $2a_1 \equiv 0 \pmod 4 \implies a_1$ 必须是偶数，所以 $a_1$ 也只能取 $0$。

     但这直接违反了“不能有两个相邻的 $0$”的规则！因此，$n$ 是 4 的倍数时**必然无解**。

2. **基准态的绝对安全与增量翻转（核心 Trick）**

   - **痛点**：如何避免构造出相邻的 $0$？

   - **跳跃**：既然 $0$ 这么危险，那我们**干脆一开始就不用 $0$**！

     考虑一个极其特殊的基准状态：除了最高位 $a_{31}=1$ 之外，其余所有位全是 $-1$。

     这个基准态的值是多少？ $2^{31} - \sum_{i=0}^{30} 2^i = 2^{31} - (2^{31}-1) = 1$。

     所以，全数组 `[-1, -1, ..., 1]` 刚好等于 **$1$**！

   - **增量构造**：既然基准值是 $1$，我们要凑到 $n$，还差 $(n-1)$。

     如何在这个数组里优雅地加上一个正数？

     - 如果把某个 $a_{i-1}$ 从 $-1$ 变成 $1$，相当于增加了 $2 \times 2^{i-1} = 2^i$。

     - 如果把 $a_0$ 从 $-1$ 变成 $0$，相当于增加了 $1 \times 2^0 = 1$。

       奇迹出现了！对于 $(n-1)$ 的二进制表示中的每一位 $1$（假设在第 $i$ 位），我们只需要修改对应位置，就能精准增加 $2^i$。并且因为我们最多只会在 $a_0$ 处产生一个 $0$，**全数组永远不可能出现相邻的 $0$**！

**编码 Trick (Coding Elegance)**

你的代码没有任何复杂的进位和分类讨论，工程美感极佳：

- **默认值填充大法**：

  `vector<int> ans(32, -1); ans[31] = 1;`

  直接用两行代码初始化基准态，彻底免去了后续填空的麻烦。

- **直接复用原变量进行位运算**：

  `x--` 将目标转化为增量后，直接用 `x >> i & 1` 遍历二进制位。将“修改状态”与“读取目标二进制”完美对齐：

  需要增加 $2^i$ $\to$ 当 $i \neq 0$ 时翻转 $a_{i-1}$ 为 $1$，当 $i = 0$ 时特判翻转 $a_0$ 为 $0$。毫无冗余。

**逻辑链条 (The Logic Chain)**

解决本题的思考步骤，浓缩为以下四步：

1. **模 4 判非**：提取前两位的同余方程 $a_0 + 2a_1 \equiv n \pmod 4$，推导出 $n \equiv 0 \pmod 4$ 必然导致 $a_0=a_1=0$，得出无解条件。
2. **确立基准**：为了规避相邻 $0$ 的约束，构造全 $-1$ 与最高位 $1$ 的基准数组，使其天然等于 $1$。
3. **转化增量**：基准值为 $1$，目标值为 $n$，转化为在基准数组上精准增加 $n-1$ 的值。
4. **位权翻转**：根据 $n-1$ 的二进制位，第 $i$ 位为 $1$ 时，若 $i>0$ 将 $a_{i-1}$ 改为 $1$（增幅 $2^i$），若 $i=0$ 将 $a_0$ 改为 $0$（增幅 $1$），输出答案。



## K  位运算（Trie）分治 + 多项式（生成函数）合并

题目极简总结

**题意**：给定两个长度为 $n$ 的序列 $a$ 和 $b$。在二分图中，左侧节点 $i$ 与右侧节点 $j$ 之间存在边的充要条件是 $a_i \oplus b_j \ge k$。

**目标**：对于每个大小 $x \in [1, n]$，求出图中大小为 $x$ 的匹配方案数，对 998244353 取模。

**数据范围**：$n \le 200$，$k < 2^{60}$。

**思路 Trick (Key Observations)**

这类涉及“全局异或大小比较”的题目，第一直觉必须是**从高到低逐位考虑（构建 01-Trie 的思想）**。难点在于，二分图匹配是一个全局问题，如何把全局匹配拆解到每一位上？

1. **异或前缀的决定性（分治基础）**

   - **痛点**：任意两个数都有可能连边，暴力建图后跑二分图匹配/状压 DP，由于边数极多且 $n=200$，必然超时。
   - **跳跃**：从最高位向下分治，将 $a$ 和 $b$ 分别按该位是 0 还是 1 划分为 $A_0, A_1$ 和 $B_0, B_1$。此时观察目标 $k$ 在这一位的值，这是全题最核心的跳跃：

2. **按位划分的独立性域（核心 Trick）**

   - **当 $k$ 的当前位为 1 时（严苛限制）**：

     为了满足异或值 $\ge k$，这一位的异或结果**必须是 1**。这意味着 $A_0$ 只能与 $B_1$ 匹配，$A_1$ 只能与 $B_0$ 匹配！

     **神奇的性质出现了**：原本纠缠在一起的图，瞬间分裂成了两个完全没有交集的独立子图 $(A_0, B_1)$ 和 $(A_1, B_0)$。它们的匹配方案互不影响，直接将两者递归返回的方案数多项式相乘即可。

   - **当 $k$ 的当前位为 0 时（宽松限制 + 剩余自由匹配）**：

     此时如果异或结果为 1（即 $A_0-B_1$ 或 $A_1-B_0$ 的连边），该位已经严格大于 $k$ 的当前位，后面的低位无论是什么，这两个点**绝对合法，构成完全二分图**。

     如果异或结果为 0（即 $A_0-B_0$ 或 $A_1-B_1$），则胜负未分，需要**继续递归**到低位判断。

     **合并逻辑**：我们先递归求出受限组 $(A_0, B_0)$ 和 $(A_1, B_1)$ 的匹配方案。对于它们内部没有匹配上的“孤儿节点”，此时可以直接扔进绝对合法的完全二分图 $(A_0, B_1)$ 和 $(A_1, B_0)$ 中随便匹配！

   - 很多选手看到 $n=200$ 这个数据范围，第一直觉都会觉得是 $O(n^3)$ 的算法（因为通常 $O(n^3)$ 在 1 秒内跑 $8 \times 10^6$ 次运算非常稳）。

     但实际上，**你这份代码的时间复杂度上限是 $O(n^4)$ 的！** 之所以它能轻松 AC 且跑得飞快，是因为它带有一个**极其微小的常数（约为 $\frac{1}{16}$）**。

**编码 Trick (Coding Elegance)**

你的代码写得非常成熟，特别是多项式的封装，让主逻辑像数学公式一样干净：

1. **多项式乘法抽象 (`poly` 和 `mult`)**：

   将不同大小的匹配数用 `vector<i64>` 封装成多项式（第 $i$ 项的系数表示匹配数为 $i$ 的方案数）。在分治合并时，两个独立连通块的匹配方案合并，本质上就是多项式乘法（卷积）。将 `mult` 抽离出来，极大地降低了分治函数 `work` 的心智负担。

2. **完全二分图匹配公式的封装 (`full` 函数)**：

   完全二分图匹配是一个标准组合数问题：两边大小分别为 $A$ 和 $B$，匹配 $i$ 对的方案数是 $\binom{A}{i} \binom{B}{i} i!$。你将其独立为 `full(a, b)`，这在 $k$ 的当前位为 0 时，计算“剩余孤儿节点的自由匹配”时直接调用，逻辑极致清晰。

3. **极简的状态转移**：

   ```cpp
   for(int i = 0; i < C[0].size(); i ++) {
       for(int j = 0; j < C[1].size(); j ++) {
           i64 base = C[0][i] * C[1][j] % mod;
           i64 a0res = A[0].size() - i, a1res = A[1].size() - j;
           i64 b0res = B[0].size() - i, b1res = B[1].size() - j;
           vector<i64> dif = mult(full(a0res, b1res), full(a1res, b0res));
           for(int k = 0; k < dif.size(); k ++) {
               res[i + j + k] += base * dif[k] % mod;
               res[i + j + k] %= mod;
           }
       }
   }
   ```

   这三行代码堪称艺术。先枚举 两个递归子问题 分别匹配了 $i$ 对和 $j$ 对，算出各自剩余的点数，然后将剩余点数直接投入 `full` 中生成自由匹配多项式，最后用 `base * dif[k]` 累加到最终结果。没有一丁点冗余的特判。

**逻辑链条 (The Logic Chain)**

1. **状态定义**：将“匹配大小为 $x$ 的方案数”映射为多项式的第 $x$ 项系数。
2. **位拆分**：从第 60 位开始递归，根据该位是 0 或 1，把点集划分为 $A_0, A_1, B_0, B_1$。
3. **位 $k=1$ 的分裂**：必须异或出 1。递归求解 $(A_0, B_1)$ 和 $(A_1, B_0)$，两者完全独立，结果多项式直接相乘。
4. **位 $k=0$ 的组合**：异或出 0 的受限组递归求解 $(A_0, B_0)$ 和 $(A_1, B_1)$；异或出 1 的交叉组直接形成完全二分图。
5. **残余图合并**：在 $k=0$ 时，枚举受限组的匹配数，将未匹配的剩余点带入完全二分图公式，再将“受限方案多项式”与“残余点自由匹配多项式”卷积合并，层层向上传递。

## L 期望自洽方程与对勾函数最值

**题目极简总结**

**题意**：初始随机抽取一个时间倒计时 $t \in [1, T]$。此后每秒倒计时减一，若减到 0，则游戏结束，你的罚时为游戏进行的总秒数。

每秒结束后，你可以选择直接等待，或者花费 1 秒的时间“刷新”倒计时（重新在 $[1, T]$ 中随机抽取一个 $t$）。

**目标**：求在最优策略下，期望罚时的最小值（以最简分数输出）。

**思路 Trick (Key Observations)**

这类题目很容易让人陷入“模拟每一秒选择”的树形概率 DP 泥潭中。破局的核心在于“自洽”与“极限化归”这三个跳跃点：

1. **破局点：阈值策略与期望自洽**

   - **痛点**：每次随机出的 $t$ 都不一样，游戏可能无限进行下去，怎么定义 DP 状态？

   - **跳跃**：假设我们已经知道了全局的最优期望罚时是 $E$。当我们面对当前的倒计时 $t$ 时，我们面临两个选择：

     - 选择等待：代价就是 $t$。

     - 选择刷新：代价是当前消耗的 1 秒，加上刷新后又面临全新局面的期望 $E$，总代价为 $1+E$。

       理性的决策必然存在一个临界阈值 $x$：当 $t \le x$ 时等待，当 $t > x$ 时刷新。

2. **跳跃点：全概率公式化简**

   - **痛点**：$E$ 是未知的，阈值 $x$ 也是未知的，如何求解？

   - **跳跃**：利用“稳态”思想，自己表达自己。根据上面的阈值策略，我们可以列出全概率方程：

     $$E = \frac{1}{T} \sum_{i=1}^{x} i + \frac{1}{T} \sum_{i=x+1}^{T} (1+E)$$

     将等式右侧展开，并把所有包含 $E$ 的项移到等号左边，化简后可以直接剥离出 $E$ 关于阈值 $x$ 的函数表达式：

     $$E(x) = \frac{x-1}{2} + \frac{T}{x}$$

     **这一步直接把无限轮的期望 DP 拍扁成了一个初等代数函数！**

3. **高光点：连续化求导与离散取点**

   - 观察 $E(x) = \frac{x}{2} - \frac{1}{2} + \frac{T}{x}$，这是一个非常标准的对勾函数。
   - 对其求导 $\frac{dE}{dx} = \frac{1}{2} - \frac{T}{x^2} = 0$，解得连续域下的极值点为 $x = \sqrt{2T}$。
   - 因为我们在现实中只能取整数阈值，所以最优的 $x$ 必然在 $\lfloor\sqrt{2T}\rfloor$ 或 $\lceil\sqrt{2T}\rceil$ 中产生。取二者代入函数比较大小即可。

**编码 Trick (Coding Elegance)**

你的代码展现了非常优秀的金牌工程素养，这两个习惯在复杂的数学/几何题中能救命：

1. **分数类的完美工程封装 (`struct frac`)**：

   在涉及输出有理分数的题目中，将分数的四则运算、通分化简（求最大公约数 `__gcd`）、正负号处理全部封装在结构体内，并重载运算符。这极大地清空了主函数中的思维负担，让主逻辑 `ans1 < ans2` 像写伪代码一样干净。

2. **`__int128` 降维打击防溢出**：

   比较两个分数大小 `a.x * b.y < b.x * a.y` 时，如果 $x$ 和 $y$ 都是 $10^9$ 级别，交叉相乘会达到 $10^{18}$ 甚至更高，稍有不慎累加就会爆 `long long`。在重载 `<` 运算符时直接强转 `(__int128)` 完美规避了潜在的溢出 WA，是一种极其稳健的防御性编程习惯。

**逻辑链条 (The Logic Chain)**

1. **策略定性**：明确最优策略必然是形如“倒计时 $>x$ 就刷新，$\le x$ 就等待”的阈值策略。
2. **状态抽象**：设全局最优期望罚时为 $E$，基于一次操作的期望建立包含自身 $E$ 的全概率状态转移方程。
3. **方程解析**：通过代数化简，将递归方程转化为 $E$ 关于未知阈值 $x$ 的显式函数 $E(x) = \frac{x-1}{2} + \frac{T}{x}$。
4. **求最优点**：利用导数或均值不等式，求出连续状态下的理论最优阈值 $x = \sqrt{2T}$。
5. **离散化收尾**：对 $x$ 上下取整，分别代入 $E(x)$ 并使用封装好的分数类进行比较，输出较小者的分子分母。

这类“建立方程自己解自己”的期望思想在后续训练中非常实用。如果现在题目稍微修改一下：**每次“刷新”操作本身是瞬间完成的，不需要消耗那 1 秒钟的代价**，你能迅速在大脑中推导出新的 $E(x)$ 表达式和最优的极值点 $x$ 吗？



### “本题与2025四川省赛C的异同”

这两道题目都属于“马尔可夫决策过程 (MDP) 求解期望最优策略”的经典题型，但它们在状态空间和转移拓扑上有着本质的差别。下面我为你详细拆解。

1. 相同点 (MDP 核心架构)

- **目标一致**：都是在每一个离散时间点面临“二元决策”（什么都不做 vs 随机刷新状态），求到达终点（时间归零 / 状态归零）的最小期望时间。

- **基础代价**：无论做哪种选择，每一次状态转移都会带来 1 秒的时间代价。

- **动态规划方程形态相似**：

  当前状态的期望代价 = $1 + \min(\text{什么都不做的期望代价}, \text{随机刷新的期望代价})$。

2. 根本差异 (全局随机 vs 局部随机)

- **上一题（倒计时题）：全局同构随机**

  不管你当前剩余时间 $t$ 是多少，只要你选择“刷新”，你面对的下一个状态**永远是**在 $[1, T]$ 中的全局均匀随机。这意味着，**从任何状态触发“刷新”，其带来的预期后续代价是一个常数 $E$**。

- **本题（图片题）：局部异构随机**

  当你处于状态 $x$ 时，你选择“刷新”，会变成 $S(x)$ 中的数。因为 $x$ 的约数和倍数集因 $x$ 而异（比如 $S(2)$ 和 $S(7)$ 完全不同），所以**在不同状态下选择“刷新”，带来的预期后续代价 $R(x)$ 是截然不同的**。

**为什么本题不能用上一题的“方程自解”法？**

上一题之所以能推导出一个优雅的连续函数 $E(x) = \frac{x-1}{2} + \frac{T}{x}$ 并直接求导，其命门在于“降维”。

在上一题中，无论有多少个状态，未知的全局最优期望罚时只有一个变量，我们称之为 $E_{global}$。我们利用 $E_{global}$ 表达了所有状态的最优决策，最后列出了一个 $E_{global} = f(E_{global})$ 的一元方程，从而在 $O(1)$ 的时间复杂度内解出了答案。

而在本题中，状态转移方程是：

$$E(x) = 1 + \min\left( E(x-1), \frac{1}{|S(x)|} \sum_{y \in S(x)} E(y-1) \right)$$

注意观察：$S(x)$ 中包含了 $x$ 的倍数，这意味着 **$E(x)$ 依赖于比 $x$ 更大的状态**。

你面对的不再是一个一元方程，而是一个包含 $N$ 个未知数（$E(1)$ 到 $E(N)$）、且带有非线性操作（$\min$）、且互相存在复杂图论依赖（倍数向后指，约数向前指）的**巨大方程组**。

数学上，**无法给出这种带 $\min$ 的异构巨大方程组的解析解（Closed-form solution）**。你必须老老实实把状态建出来，把它当成一个图论问题，使用 **Dijkstra 算法**（因为时间代价总是 $+1$，相当于边权为正的最短路）或者 **值迭代 (Value Iteration)** 来数值求解。

**假设上一题不要求精确分数，能用值迭代 (VI) 吗？**

理论上绝对可以，但实际上会 TLE（超时）到绝望。

如果上一题不要求输出精确分数，我们完全可以写出它的 MDP 值迭代代码：

初始化一个数组 $V[1 \dots T] = 0$，然后不断迭代更新：

$$V_{new}[t] = \min\left(t, 1 + \frac{1}{T} \sum_{i=1}^{T} V_{old}[i]\right)$$

直到 $V$ 数组收敛。

**为什么出题人不用这个解法？请看数据范围：**

上一题的 $T$ 高达 $10^9$！

如果你用值迭代，状态空间大小是 $10^9$。且不说迭代多少轮能收敛，光是把这个数组在内存里遍历一遍，就需要几秒钟时间，空间上更是直接 MLE（超内存）。

所以，上一题的 $O(1)$ 数学解析解**不是为了应付分数输出，而是为了把时间复杂度从 $O(T)$ 强行降维到 $O(1)$ 的唯一出路。**

**总结与 ICPC 刷题启发**

这两道题完美构成了一组对照实验，揭示了算法竞赛中处理期望问题的两条经典科技树：

1. **全局状态同构（所有未知的终点都指向同一个宏观期望）** $\longrightarrow$ **代数降维**（设元、列全概率方程、求导极值）。对应上一题，所以敢把 $T$ 开到 $10^9$。
2. **局部状态异构（状态转移错综复杂，形成网状图）** $\longrightarrow$ **图论求值**（建图、SPFA/Dijkstra、值迭代 DP）。对应本题，这也是为什么本题的 $N$ 只有 $10^5$（$O(N \log N)$ 级别边数的 Dijkstra 极限）。
