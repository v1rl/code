## C 增量贡献拆解与在线 KMP 失配 DP

**题目极简总结**

**题意**：维护一个初始为空的字符串 $S$。每次在末尾追加一个字符 $S_i$（强制在线），同时给出 $A_i, B_i$。每次操作后需要输出 $\sum_{i=1}^n \sum_{j=i}^{i+z_i-1} A_j \times B_i$，其中 $z_i$ 是后缀 $S[i \dots n]$ 与前缀 $S[1 \dots n]$ 的最长公共前缀（LCP）长度。

**思路 Trick (Key Observations)**

这道题最核心的难点在于：公式里有 $z_i$，看起来像是要求 Z-函数（扩展 KMP），但 Z-函数很难高效地在线维护。破局点在于**不要去求 $z_i$，而是去看第 $n$ 步对答案产生了什么增量。**

1. **增量法与贡献拆解 (数学跳跃)**
   - **痛点**：每次更新都要计算所有后缀的 LCP，复杂度爆炸。
   - **跳跃**：考察当加入第 $n$ 个字符 $S_n$ 时，内层求和 $\sum_{j=i}^{i+z_i-1} A_j$ 发生了什么变化。
   - **推演**：如果后缀 $S[i \dots n]$ 还能和前缀匹配，说明它的 LCP 从 $n-i$ 涨到了 $n-i+1$。此时，内层循环的上限增加了 $1$，恰好把 $A_n$ 给纳入了求和范围！如果它失配了，它的 LCP 就永远定格了，以后再加字符也不会把 $A_n$ 加进去。
   - **结论**：第 $n$ 步时，答案的增量 $\Delta ans = A_n \times \sum B_i$ （满足条件：后缀 $i$ 目前依然和前缀完全匹配）。我们将复杂的 LCP 问题，降维成了**维护当前处于“存活”状态的匹配后缀的 $B_i$ 之和**！
2. **有效后缀与 KMP Border 的等价映射 (字符串跳跃)**
   - **痛点**：如何在线维护哪些后缀“存活”、哪些“死亡”（失配）？
   - **跳跃**：一个后缀 $S[i \dots n]$ 等于前缀 $S[1 \dots n-i+1]$，这在字符串理论中叫做 **Border**！
   - **结论**：存活的后缀集合，恰好就是当前字符串的所有 Border。加入新字符 $S_n$ 时，我们只需要找出哪些 Border 无法扩展（即 $S_{L+1} \neq S_n$），从总和中减去它们的 $B_i$ 即可。这就完美转化为了 KMP 算法。

**编码 Trick (Coding Elegance)**

你代码中最精彩的部分是引入了 `fails[i]` 数组。这是一个神来之笔，相当于在 KMP 自动机上做了一次 DP。

- **痛点**：标准的 KMP `while(j && s[i] != s[j]) j = ne[j-1]` 循环，确实能跳过失配的 Border，**但它只能找出比最终存活的 Border 更长的那些失配 Border**。如果存在比最终存活 Border 更短的 Border 也失配了，标准的 KMP 循环是不会遍历到它们的！

- **编码 Trick：KMP 失配树上的状态继承 (DP)**

  你的代码中：

  ```cpp
  if(s[i] == s[j]) {
      for(auto x : fails[j]) fails[i].emplace_back(x);
  }
  ```

  - **原理解释**：`fails[i]` 记录的是“试图与 $S_i$ 匹配时，所有断裂的 Border 长度”。当 `s[i] == s[j]` 匹配成功时，比 $j$ 更短的那些失配 Border 去哪找？它们恰好就是“试图与 $S_j$ 匹配时断裂的 Border”！所以直接继承 `fails[j]`。
  - **优雅之处**：通过显式地维护 `fails` 数组，你用均摊 $O(1)$ 的状态转移，极其精准地捕捉到了**所有**在当前字符死亡的 Border，随后统一执行 `pre -= b[i - x]`，逻辑闭环，无需任何复杂的数据结构。

### 逻辑链条 (The Logic Chain)

1. **视角反转**：不求全局的 LCP，改求第 $n$ 步加入时 $A_n$ 对全局答案的增量贡献。
2. **提炼系数**：发现 $A_n$ 的系数就是“当前依然与前缀匹配的所有后缀的 $B_i$ 之和”，记为 `pre`。
3. **转化 Border**：将“匹配的后缀”转化为“当前前缀的 Border”，纳入 KMP 算法体系。
4. **增量维护 `pre`**：每读入一个字符，无条件将它的 $B$ 计入 `pre`（因为它自己构成长度为 1 的 Border），并剔除那些在这一步失配的 Border 的 $B_i$。
5. **精准剔除（失配 DP）**：利用 `fails[i]` 数组，在 KMP 跳跃和匹配时，继承并记录所有失配的 Border 长度，实现快速剔除，完成状态流转。
