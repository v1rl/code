## C **连续空域连通块扫描线与补集并查集**

------

**一句话题意**

无限网格中有 $n$ 个障碍点（坐标 $\le 10^6$），八连通的障碍点会形成封闭围墙。现有 $q$ 个非障碍询问点，判定它们是否被**任意**一道围墙封闭（即无法四连通走到无穷远处）。

（数据范围：$n \le 5 \times 10^4$，$q \le 10^5$）

------

**思路 Trick：关键思维跳跃**

在 XCPC 中，处理“几何连通性”与“封闭区域判定”时，正面去寻找多边形或计算几何包围判定往往会陷入极复杂的分类讨论（如射线法穿墙、多连通分量等）。本题完成思维跃迁的核心在于“正难则反”的补集转换与降维扫描：

1. **“能否出去”的等价拓扑转换（超级源点联结）**
   - 题目问点是否在“炮火圈”内，本质是问：**该点所在的“空白网格连通块”能否延伸到无穷远**。
   - 既然坐标上限只有 $10^6$，我们可以直接框定一个略大一点的边界（例如 $x, y \in [0, 10^6+2]$）。外部区域天然连通且代表“无穷远”。
   - 于是问题转化为：**维护所有空白连通块，判断询问点所在的连通块是否和“外部超级连通块（包含边界的空白段）”属于同一个集合。**
2. **自变量离散化与降维切片（X轴事件驱动）**
   - 尽管网格范围是 $10^6 \times 10^6$，但障碍点只有 $5 \times 10^4$ 个。大部分 X 坐标对应的整列全都是空白的。
   - 关键跳跃：如果仅离散化出现过障碍点的 $X_i$，中间跨过的大片空白区域如何表达？
   - **Trick**：将每个出现过障碍的 $X_i$ 以及紧邻它的右侧一列 $X_i + 1$ 共同加入离散化数组。这样，任意相邻的两个离散化 X 坐标之间，要么是同一列，要么代表一段完全同构的连续空白带。将二维网格压缩成了 $O(n)$ 列的有效切片。
3. **双指针扫描线合并（一维区间拓扑图）**
   - 在单独一列中，被障碍点切分出来的若干段连续空白区间 $[L_k, R_k]$，内部天然四连通，可以作为一个**独立的缩点（ID）**。
   - 相邻两列的空白区间如何连通？只要前一列的空白区间 $[l_1, r_1]$ 与后一列的空白区间 $[l_2, r_2]$ **在 Y 轴上有交集**（即 $\max(l_1, l_2) \le \min(r_1, r_2)$），它们在网格上必然四连通。
   - 利用双指针（Two Pointers）在 $O(|A| + |B|)$ 线性时间内即可完成相邻两列所有交集区间的并查集合并。

------

**编码 Trick：优雅实现范式**

你的 AC 代码极其干练，完美规避了离散化坐标映射时容易出现的越界或空指针问题，展现了金牌选手的工程素养：

1. **天然内定“超级源点”**

   ```cpp
   vector<int> kth {0, inf}; // 初始化塞入边界
   ```

   在离散化 X 坐标时，直接把 `0` 和 `inf`（$10^6+2$）塞入基准池。由于列内构建区间时，第一列（`x=0`）必然没有障碍点，它会生成一个跨越整条 Y 轴的巨大空白区间 $[0, \text{inf}]$，且被分配为 `ID = 1`。后续判定直接查 `dsu.same(..., 1)` 即可，零成本完成了无穷远连通块的锚定。

2. **一维连续段的极简补集切割**

   ```cpp
   int lst = 0;
   vec[i].emplace_back(inf);
   sort(vec[i].begin(), vec[i].end());
   for(auto y : vec[i]) {
       if(y > lst) seg[i].push_back({lst, y - 1, ++ cnt});
       lst = y + 1;
   }
   ```

   不需要复杂的扫描线线段树。由于单列点数极少，给该列末尾追加一个虚拟障碍物 `inf`，然后用 `lst` 记录上一个障碍物的上方位置。每次遇到新障碍物 `y`，直接提取区间 `[lst, y - 1]`。这段逻辑天然过滤了重复坐标和紧挨着的点（此时 `y <= lst`，不会触发 `push_back`），干净利落地完成了补集切分。

3. **双指针交集判定与平移的解耦**

   ```cpp
   if(r1 < r2) {
       if(r1 >= l2) dsu.merge(id1, id2);
       x ++;
   } else {
       if(r2 >= l1) dsu.merge(id1, id2);
       y ++;
   }
   ```

   判断两个区间相交的极简条件是 `右端点最小值 >= 左端点最大值`。但在双指针推进时，你依据的是**谁的右端点更小谁就往前走**（`r1 < r2` 决定 `x++` 还是 `y++`）。这种推进逻辑完美覆盖了一对多、多对多的区间交叠情况，逻辑极其清晰。

4. **二分定位询问点的双重映射**

   ```cpp
   x = upper_bound(kth.begin(), kth.end(), x) - kth.begin() - 1;
   y = upper_bound(seg[x].begin(), seg[x].end(), array{y, inf, inf}) - seg[x].begin() - 1;
   ```

   对于询问点 $(x, y)$，先利用 `upper_bound - 1` 找到离散化后它所属的列切片索引；再在该列的所有空白区间中，利用 `upper_bound - 1` 找到它落入的具体空白区间 ID。全程无缝衔接 STL，无需手写繁琐的区间查找逻辑。

## D **贡献拆分与路径生长动态DP**

------

**一句话题意**

给定一棵 $n$ 个节点的树，点权为 $0 \sim n-1$ 且互不相同。定义树上连通子图的权值为其包含节点权值集合的 $\text{MEX}$。求所有连通子图的权值之和对 $10^9+7$ 取模的结果。

（数据范围：$n \le 2 \times 10^5$）

------

**思路 Trick：关键思维跳跃**

在 XCPC 中，面对“求所有连通块/区间 $\text{MEX}$ 之和”类问题，直接按连通块枚举是 $O(2^n)$ 级别的灾难。本题的核心 Trick 在于**利用 $\text{MEX}$ 的单调前缀约束进行“贡献拆分”，将静态子图计数转化为树上确定性路径的动态维护**：

1. **值域到连通块的贡献拆分（正难则反的期望式思维）**

   - 传统视角：枚举连通块 $\to$ 计算其 $\text{MEX}$ $\to$ 求和。
   - **跳跃视角**：考虑单个权值 $k$ 能够作为答案被计入多少次。一个连通块的 $\text{MEX}$ 等于 $k$，当且仅当该连通块**包含了权值 $0 \sim k-1$ 的所有节点，且绝对不包含权值为 $k$ 的节点**。
   - 更进一步：基于等式 $\sum \text{MEX}(S) = \sum_{k=1}^{n} [0 \sim k-1 \in S]$，我们只需计算“**完美包含 $0 \sim k-1$ 所有节点的连通子图数量**”，记为 $C(k)$。答案即为 $\sum_{k=1}^{n} C(k)$。

2. **树上路径的极简拓扑收束（核心结构剖析）**

   - 要让一个连通块同时包含权值为 $0, 1, \ldots, k-1$ 的节点，由于树上任意两点间路径唯一，该连通块必须完全覆盖连接这些点的**极小连通子树**。
   - 关键跳跃：如果以权值为 $0$ 的节点（记为 $root$）作为整棵树的根，那么当新加入节点 $k-1$ 时，连通块必须覆盖从 $root$ 到 $k-1$ 对应节点所在的那条链。
   - 随着 $k$ 的递增，目标连通块的核心骨架只会在树上沿着根向叶子的方向**单调生长**。

3. **连通块扩展方案的 DP 抽象与乘法原理解耦**

   - 在以 $root$ 为根的树中，任意节点 $u$ 的“连通块向下扩展方案数”定义为 $dp[u]$：表示以 $u$ 为顶部节点，在 $u$ 的子树内部选择一个包含 $u$ 的连通块（或不选任何点，仅当 $u$ 非必须包含时）的方案数。

   - 转移方程天然满足乘法原理：

     $$dp[u] = \prod_{v \in son(u)} dp[v] + 1$$

     （$+1$ 代表不选 $u$ 的任何子树节点，连通块在 $u$ 处截断；若强制选中 $u$，则去掉 $+1$）。

   - 当核心骨架从根生长到叶子时，骨架上的节点变为“强制选中状态”，其对总方案数的贡献从“可选可不选的 $dp[x]$”退化为“必须向下延伸的 $(dp[x]-1)$”。

------

**编码 Trick：优雅实现范式**

你的 AC 代码不仅在变量作用域控制上做到了极致纯净，在维护树上动态连通块时展示了极为老道的避坑技巧：

1. **父节点数组重载与隐式换根**

   C++

   ```cpp
   dfs(dfs, p[0]); // 直接以权值为 0 的点 p[0] 作为 DFS 起点
   ```

   没有单独写换根逻辑或二次建树。通过直接以权值为 $0$ 的点作为 DFS 入口，利用 DFS 过程顺手覆写了全局数组 `p`（利用作用域遮蔽，将原本存坐标的 `p` 优雅过渡为存树上 `parent` 指针的 `p`），使整棵树的拓扑结构天然以 $root$ 为中心向下发散。

2. **暴力跳父亲的均摊线性维护（树上染色法）**

   C++

   ```cpp
   while(x >= 1 && !vis[x]) {
       vis[x] = true;
       div(dp[x]); mul(dp[x] - 1);
       x = p[x];
   }
   ```

   当连通块需要向新节点 $x$ 生长时，直接暴力执行 `x = p[x]` 往上爬，同时利用 `vis` 数组记录节点是否已被纳入核心骨架。一旦碰到已染色的祖先立刻退出。由于每个节点至多被染色一次，全局爬树的总复杂度被严格收束在均摊 $O(n)$。

3. **惰性乘除运算的零权值封装（避免逆元除零崩溃）**

   ```cpp
   int pw = 0;
   auto mul = [&](Z x) { if(x == 0) pw ++; else res *= x; };
   auto div = [&](Z x) { if(x == 0) pw --; else res /= x; };
   ```

   **这是本题最具含金量的工程 Trick。** 在执行子树贡献替换时，需要除以原本的 $dp[x]$ 并乘上更新后的值。由于模意义下 $0$ 没有逆元，直接做除法必然导致程序 RE。代码通过封装一个全局零计数器 `pw`，将 $0$ 的乘除转化为对计数器的加减，仅在 `pw == 0` 时认定连通块乘积有效。完美实现了 $O(1)$ 的安全动态替换。

------

**解决本题思路的逻辑链条**

1. **目标转化**：将求 $\text{MEX}$ 总和转化为求“同时包含权值 $0 \sim k-1$ 的连通子图数量”的累加和。
2. **基准确立**：以权值为 $0$ 的节点作为整棵树的根节点重新定向整棵树。
3. **静态预处理**：自底向上 DP 计算出每个子树自由向下选择连通块的原始方案数 $dp[u] = \prod dp[v] + 1$。
4. **拓扑定界**：初始方案总数即为根节点的必选子树乘积，记答案起点为 $\prod_{v \in son(root)} dp[v]$。
5. **贡献修正**：沿途将新增链上所有节点的子树选择权剥夺，利用惰性乘除法将总方案中的 $dp[x]$ 实时替换为强制选中的 $(dp[x]-1)$。
6. **答案累加**：若当前未出现必定断开的零贡献节点（`pw == 0`），则将维护的乘积计入总答案。



## E **L型同心剥离与连通块极简构造**

------

**一句话题意**

构造一个 $n \times n$ 的 `01` 矩阵，满足：

1. 每行和的集合、每列和的集合均恰好为 $\{0, 1, \dots, n-1\}$。

2. 矩阵中 `0` 的连通块数量与 `1` 的连通块数量之和**恰好为 $n$**（四连通）。

   （数据范围：$n \le 10^3$）

------

**思路 Trick：关键思维跳跃**

这类题目在 XCPC 赛场上常被称为“脑筋急转弯”或纯粹的构造题。如果试图用回溯搜索或分块拼接，极易陷入连通块计数的泥潭。破局的核心在于“强对称性映射”与“同心降维打靶”：

1. **行列和满射的强对称锁定（行列等价推导）**
   - 题目要求行列和的集合都是 $0 \sim n-1$ 各出现一次。这意味着矩阵中必然有一行全 `0`、一列全 `0`；同时也必然有一行仅含一个 `1`、一列仅含一个 `1`……以此类推。
   - **跳跃点**：既然行和列的要求完全一致，最容易满足条件的形式必然是**主对角线对称矩阵**（$A_{i,j} = A_{j,i}$），这样只要搞定行，列自然满足。
2. **从“行列和递增”到“L型同心剥离”（拓扑降维）**
   - 如何让行和分别达到 $0, 1, 2, \dots, n-1$？
   - 考虑从外向内一层层填数：
     - 最外层填一圈全 `0`（占满第 $0$ 行和第 $0$ 列），此时第 $0$ 行/列的和确定为 $0$。
     - 剩下的内部空间变成了一个 $(n-1) \times (n-1)$ 的子矩阵。我们在它的最外围包裹一层反转颜色（填全 `1`），此时第 $1$ 行/列除了开头的 `0` 之外全被 `1` 填满，和恰好为 $n-1$（或对应反转后的互补值）。
   - 这种“一层 `0`、一层 `1` 交替往里套”的结构，在矩阵上切分出了 $n$ 个嵌套的 **L 型区域**（包含单点核心）。
3. **连通块数量的天然收束（注意力跳跃点）**
   - 连通块限制要求总数恰好为 $n$。
   - 观察上述构造的 L 型嵌套结构：每一个 L 型内部颜色相同，且天然连通；相邻两层 L 型颜色互异，形成物理隔离。
   - 既然一共套了 $n$ 层 L 型（最核心层退化为 $1 \times 1$ 单点），那么**恰好生成了 $n$ 个交替包裹的连通块**！构造目标瞬间三线合一完美闭环。

------

**编码 Trick：优雅实现范式**

你在代码注释里写了“废料构史题”，这确实反映了这类题目“想通一秒钟，想不通牢底坐穿”的特质。但你的 AC 代码将这个极为精妙的图形学构造压缩成了一行极简代数式，堪称艺术：

1. **切比雪夫距离的代数极简映射**

   ```cpp
   cout << min(i, j) % 2;
   ```

   **这是全场最高光的实现技巧。** 如何用坐标 $(i, j)$ 判定当前格子属于由外向内数第几层 L 型？

   - 注意到矩阵左上角坐标为 $(0, 0)$。某点到上边界的距离是 $i$，到左边界的距离是 $j$。
   - 决定它属于哪一层 L 型边界的，恰恰是它离左上角原点的**轴向最短深度**，即 $\min(i, j)$。
   - 利用 `% 2` 轻松实现相邻层 `0` 和 `1` 的交替翻转。完全免去了分层循环、边界控制等极易写错的代码，做到**零思维、零边界负担**。

------

**解决本题思路的逻辑链条**

1. **目标分析**：需同时满足行列和全覆盖映射与严苛的连通块计数限制。
2. **对称降维**：利用主对角线对称性，将“行列双重限制”坍缩为单一维度构造。
3. **连通锚定**：要凑出恰好 $n$ 个连通块，最直接的几何拓扑模型是 $n$ 个互相包裹的独立单色层。
4. **层级抽象**：在方阵中实现“互相包裹”的最佳几何切片形态为左上对齐的嵌套 **L 型区域**。
5. **权值验证**：交替填充 `0` 和 `1` 的嵌套 L 型，天然使各行/列的 `1` 个数呈现单调阶梯状分布，完美契合 $0 \sim n-1$ 的和值集合。
6. **坐标映射**：观察得出任意点 $(i, j)$ 所在的嵌套层数严格等于 $\min(i, j)$，直接通过模 $2$ 映射输出。



## G **持有量门槛单调映射与CDQ分治**

------

**一句话题意**

给定长度为 $n$ 的数组 $a$，从起点 $s$ 出发向右遍历至末尾。初始持有量 $sum = a_s$。对于后续位置 $i > s$，当且仅当 $sum \ge a_i$ 时可将 $a_i$ 累加入 $sum$。求对于每个起点 $s \in [1, n]$，最终能达到的最大持有量。

（数据范围：$\sum n \le 2 \times 10^6$）

------

**思路 Trick：关键思维跳跃**

这类“向右吸收合并”的问题在正常视角下会因为每个起点的初始权值不同，导致后续吸收链条产生非线性的分支。破局的核心在于“状态合并的代数门槛分析”与“分治降维转移”：

1. **门槛等价性转换（代数底座）**

   对于左半区间的一个确定起点 $s$（此时已在左区间累积了最终权值 $ans_s$），它试图向右半区间延伸。它能顺利吃掉右半区间某个位置 $j$ 的前提条件是：**当前累积量必须大于等于 $j$ 在右区间独立视角下的“吸收准入门槛” $val_j$**。

   - **跳跃点**：右区间位置 $j$ 的独立门槛 $val_j$ 并非单纯的 $a_j$。如果 $j$ 之前的位置已经被吃掉并贡献了权值总和 $lv$，那么要吃掉 $j$，只需满足初始进入右区间的权值加上 $lv$ 大于等于 $j$ 的原门槛即可，即进入权值需达到 $val_j - lv$。

2. **门槛与贡献的双指针单调映射（CDQ核心设计）**

   - 既然转移关系是“左边的输出 $ans_s$ 去碰撞右边的输入门槛 $val_j$”，这天然符合 **CDQ 分治（基于时间的偏序贡献拆分）** 的架构。
   - 在分治合并阶段，若我们将左区间按当前总持有量 $ans$ 升序排列，右区间按准入门槛 $val$ 升序排列，即可利用双指针在 $O(len)$ 时间内算出左边每个点恰好能吃掉右边多少前缀贡献。

3. **右半区间门槛归并的“前缀短板效应”（注意力跳跃点）**

   - 在跨区间合并完答案后，如何维护当前大区间 $[l, r]$ 对外部更右区间的整体准入门槛？
   - 右区间元素在左区间元素的辅助下，门槛发生了动态降低（即 $val_j - lv$）。但需要注意，要吃掉 $j$，必须先跨过它左侧所有元素设置的复合关卡。
   - 因此，大区间内排序后元素的新准入门槛，严格等于其自身降低后的门槛与前面所有已跨越关卡门槛的**前缀最大值**（代码中的 `lst = max(lst, val[q[j]] - lv)`）。这使得离散的吸收条件坍缩为单调递增的线性阶梯。

------

**编码 Trick：优雅实现范式**

你的代码在处理多维属性（当前答案 $ans$ 与准入门槛 $val$）的动态排序时，避免了结构体频繁拷贝的时间开销，展示了极为老道的底层常数优化技巧：

1. **多态指针数组解耦归并**

   ```cpp
   vector<int> p(n + 1), q(n + 1);
   ```

   没有用庞大的结构体去同时承载 $a, ans, val$ 并重载运算符，而是开辟了两个独立的索引数组：`p` 专门追踪按 $ans$ 排序的下标序列，`q` 专门追踪按 $val$ 排序的下标序列。在 CDQ 递归中对这两个指针序列分别维护，极大降低了内存交换开销。

2. **内置归并函数的极简重构**

   ```cpp
   inplace_merge(p.begin() + l, p.begin() + mid + 1, p.begin() + r + 1, 
       [&](int x, int y) { return ans[x] < ans[y]; });
   ```

   对于单纯保留原有值大小顺序的 `p` 数组，直接调用 STL 的 `inplace_merge` 配合 Lambda 表达式完成线性合并，省去了手写临时数组 `tmp` 倒腾的代码，兼顾了极简可读性与高效执行。

3. **门槛推演与指针重排的一体化双核循环**

   ```cpp
   if(i <= mid && (j == r + 1 || val[q[i]] < val[q[j]] - lv)) {
       lst = val[q[i]]; lv += a[q[i]]; tmp[k ++] = q[i]; i ++;
   } else {
       lst = max(lst, val[q[j]] - lv); val[q[j]] = lst; tmp[k ++] = q[j]; j ++;
   }
   ```

   **这是整份代码思维密度最高的一段。** 在对 `q` 数组按新门槛进行归并排序的同时，利用双指针天然的先后顺序，顺手完成了左侧累积贡献 `lv` 的动态追踪，并原地覆写了右侧降维后的门槛 `val[q[j]] = lst`。一个循环干了状态转移、前缀Max维护、归并排序三件事，没有任何多余动作。

------

**解决本题思路的逻辑链条**

1. **状态解耦**：将任意起点的吸收过程拆分为“自身累积权值 $ans$”与“对更右侧元素的准入门槛 $val$”两个正交属性。
2. **分治切分**：定义 CDQ 分治结构，先递归处理左区间 $[l, mid]$ 和右区间 $[mid+1, r]$ 内部的独立吸收与门槛构建。
3. **跨界贡献**：利用左侧按 $ans$ 有序的序列与右侧按 $val$ 有序的序列展开双指针碰撞，将右侧合法的独立权值批量累加入左侧答案。
4. **门槛更新**：将左侧总权值作为辅助支援注入右侧，动态削减右侧元素的绝对准入门槛（$val_j - lv$）。
5. **短板传递**：应用前缀最大值逻辑消解内部断层，确保合并后大区间的整体准入门槛单调不降。
6. **线性收束**：分别维护双指针索引序列完成当前区间的状态收束，确保分治整体时间复杂度严格控制在 $O(n \log n)$。

------

”为什么要`lst = max(lst, val[q[j]] - lv);`“

- 前面的 `if` 保证的是：在吃掉 $i$ **之前**的那一瞬间，$val_i$ 确实小于当时的 $val_j - lv_{old}$。
- 但吃掉 $i$ **之后**，由于 $lv$ 瞬间膨胀了 $a_i$，$val_j - lv_{new}$ 完全可能发生断崖式下跌，跌破 $val_i$。
- 因此，`max` 操作本质上是在维护“木桶短板效应”——无论后续关卡因为前缀支援变得多么容易，通关的整体门槛绝不能低于沿途任何一个前置关卡的绝对门槛。



## H **贡献拆分与首次出现映射**

------

**一句话题意**

给定长度为 $n$ 的数组 $a$。定义一个子数组的权值为：**该子数组所有前缀的不同元素个数之和**。求数组 $a$ 所有非空子数组的权值总和。

（数据范围：$\sum n \le 10^5$）

------

**思路 Trick：关键思维跳跃**

在 XCPC 竞赛中，如果题目出现“所有子数组的某种统计量之和”，且直接按子数组枚举的时间复杂度爆炸（如 $O(N^3)$ 或 $O(N^2)$），核心破局思路必然是“贡献拆分”（Contribution Technique）。本题完成 $O(N)$ 线性降维的核心在于两步思维跳跃：

1. **双重统计量的解耦与重构（代数视角的跳跃）**
   - **伪代码逻辑翻译**：题目中的函数 $f(1, m, s)$ 本质上是在遍历子数组 $s$ 的每个前缀 $s[1 \dots j]$，统计该前缀的不同元素个数，然后全部加起来。
   - **暴力视角**：$\sum_{\text{子数组 } L \dots R} \sum_{j=L}^{R} (\text{前缀 } L \dots j \text{ 中不同元素的个数})$。
   - **贡献视角转换**：与其枚举区间再算元素，不如**直接考察原数组中每一个具体位置 $i$ 上的元素 $a_i$ 能作为“有效贡献”被计入答案多少次**。
2. **“首次出现去重法”与管辖区间的精准锁定（核心 Trick）**
   - 在一个确定的统计区间 $L \dots j$ 中，元素 $X$ 能使不同元素个数 $+1$ 的充要条件是：**该区间内包含至少一个元素 $X$**。
   - 为了避免同一个 $X$ 在同一个区间内被重复统计，经典的计数技巧是：**强制让该区间内最左侧（即下标最小）的那个 $X$ 作为唯一的贡献代表**。
   - 于是，位置 $i$ 上的元素 $a_i$ 能够作为“有效代表”贡献给某个前缀 $L \dots j$ 的充要条件是：
     1. 前缀的终点 $j$ 必须包含或越过 $i$（即 $j \ge i$）。
     2. 前缀的起点 $L$ 必须包含 $i$，且**绝对不能包含上一个值相同的元素位置 $lst_i$**（即 $lst_i < L \le i$）。
   - 独立乘法原理组合：
     - 起点 $L$ 的可选方案数为：$(i - lst_i)$。
     - 对于每一个确定的起点 $L \le i$，终点 $j$ 的取值范围是 $i \le j \le R$。注意原数组总长度为 $n$，$R$ 最大可延伸至 $n$。对于固定的起点 $L$，合法的终点 $j$ 构成的有效统计前缀数量恰好对应了右侧剩余的扩展长度。通过对右侧长度进行前缀和预处理，即可将终点 $j$ 的自由度完美收束。

------

**编码 Trick：优雅实现范式**

你的 AC 代码不仅常数极小，而且在处理“上一个位置”以及贡献乘积的组合上展示了极为老道的避坑技巧：

1. **利用 `unordered_map` 与默认零值极简构建 $lst_i$**

   C++

   ```cpp
   if(mp.count(a[i])) lst[i] = mp[a[i]];
   mp[a[i]] = i;
   ```

   没有采用离散化加静态数组的繁琐写法。利用哈希表动态记录最近出现位置，且当元素首次出现时，`lst[i]` 默认保留初始化状态的 `0`。由于数组下标从 `1` 开始，`lst[i] = 0` 恰好完美契合了起点的边界取值范围 $0 < L \le i \implies 方案数 (i - 0)$，天然免去了针对首次出现元素的特殊特判。

------

解决本题思路的逻辑链条

1. **题意翻译**：将伪代码抽象为计算“所有子数组的所有内部前缀的去重元素个数总和”。
2. **视角转换**：放弃按子数组枚举，转而思考原数组每个独立位置 $i$ 上的元素对总和的贡献次数。
3. **去重定界**：引入“首次出现去重原则”，规定只有当位置 $i$ 是统计区间内该数值的最左侧元素时才计入贡献。
4. **左界锁定**：确定使位置 $i$ 成为合法代表的子数组左端点 $L$ 的可行域严格为 $(lst_i, i]$，方案数为 $i - lst_i$。
5. **右界打包**：观察得出对于任意合法的左端点，右侧终点 $j$ 的合法延伸范围总和严格对应等差数列之和，利用 $res[n - i + 1]$ 静态解耦。
6. **线性收束**：利用哈希表边读边记录 $lst_i$，套用组合公式累加每个位置的独立乘积，算法闭环。



## J **按级降序多源BFS与状态继承**

------

**一句话题意**

给定一张 $n$ 个点 $m$ 条边的无向图。定义点权 $d_x$ 为点 $x$ 的度数。对每个点 $x$，求从它出发到达任意一个**点权严格大于 $d_x$** 的点的最短路径长度。若无法到达输出 `-1`。

（数据范围：$n, m \le 2 \times 10^5$）

------

**思路 Trick：关键思维跳跃**

在 XCPC 赛场上，如果直观地从每个点出发去执行 BFS 寻找更高一级的点，面对 $O(n)$ 次单源最短路，整体复杂度会飙升至 $O(n(n+m))$ 从而直接 TLE。本题的核心 Trick 在于利用“正难则反与多源汇聚”实现全局视角的降维扫描：

1. **多源终点倒推（正难则反的跳跃）**
   - 顺推视角：每个点去茫茫图海中找比自己度数大的点。
   - **跳跃视角**：将目标反转为“高层级的点主动向下层级的点辐射最短路”。
   - 既然所有度数为 $U$ 的城市都是它严格低级别城市（度数 $< U$）的潜在合法终点，我们可以将所有度数为 $U$ 的点作为超级源点集合，同时压入队列展开多源 BFS。
2. **按层级降序的单调状态继承（全局均摊优化的核心）**
   - 如果仅对每一级单独做反向 BFS 并每次清空 `dist` 数组，总复杂度依然可能退化为 $O(k \cdot (n+m))$。
   - **核心跳跃**：注意观察最短路的传递传递性。如果一个点 $y$（度数 $< U$）被度数为 $U$ 的源点更新了最短距离 $dist_y$，那么在后续处理更低级别时，**$y$ 本身就已经携带了通往 $\ge U$ 级别城市的最短路信息**！
   - 只要我们将所有出现的度数从大到小（$n \to 1$）依次作为辐射源，每次启动 BFS 时**不清空**全局距离数组 `dist`，而是让上一层级更新出的残余距离自然作为下一层级的中间跳板继续向下拓展。
   - 这种“高水位向低水位漫灌”的单调性保证了每一条边在整个降序扫描过程中仅被有效访问极少次数，将全局总时间复杂度完美压缩至 $O(n + m)$ 线性级别。

------

**编码 Trick：优雅实现范式**

1. **桶排序统计层级（零开销离散化）**

   ```cpp
   for(int i = 1; i <= n; i ++) cnt[d[i]] ++;
   ```

   没有使用繁琐的 `std::map` 或显式对数组去重排序来提取层级 $a_1 \dots a_k$。由于度数的值域天然受限于 $[0, n-1]$，直接开辟一个计数桶 `cnt`。外层直接从 $n$ 倒序遍历到 $1$，若 `cnt[i]` 为零则顺手 `continue`。这一步天然完成了**层级的自动降序与去重**，零思维负担。

2. **复用距离数组的双重标记过滤**

   ```cpp
   if(d[y] < U) {
       if(ans[y] > dist[x] + 1) {
           ans[y] = dist[y] = dist[x] + 1; // 答案与中间态同步继承
           q.push(y);
       }
   }
   ```

   在 BFS 拓展时，巧妙地结合了显式层级屏障 `d[y] < U` 与距离松弛条件。

   - 只有严格低于当前主源点度数 $U$ 的邻居才被允许入队，这有效截断了同级或高级别点之间的无效横向/逆向反推。
   - 每次成功拓展时，同时覆写答案数组 `ans[y]` 和当前轮次的传递距离 `dist[y]`，保证了逻辑的一致性与状态的无缝下传。

------

解决本题思路的逻辑链条

1. **题意转化**：将问题抽象为多源汇最短路模型，求每个点到最近的高权值点的距离。
2. **视角倒转**：采用“正难则反”策略，由高权值点向低权值点反向倒推最短路径。
3. **降序定界**：利用度数天然受限的特性建立计数桶，确定自顶向下的层级遍历次序。
4. **状态复用**：确立分阶段多源 BFS 架构，每一轮将当前最高度数集合作为起点批量入队。
5. **全局继承**：在跨层级转移时保留底层距离数组 `dist`，允许间接最短路顺着下降的权值链无缝下传。
6. **收束输出**：扫描完毕后判定不可达状态（`inf` 映射为 `-1`），以严格的线性时空开销结束算法。
