## B **极小值截断与不变消耗前缀排列**

------

**一句话题意**

给定 $2n$ 张牌构成的全排列，平分为小茉（集合 $A$）和小红（固定序列 $B$）各 $n$ 张。游戏每轮对比双方牌库顶，大的一方得 $1$ 分并消耗该牌，小的一方不得分且牌**留在原地**。求小茉重新排列自己的手牌 $A$，使得自己**得分最大化**的不同排列方案数，对 $998244353$ 取模。

- **核心特征**：对手小红的出牌顺序 $B$ 是完全锁死且公开的。赢牌方消耗，输牌方卡牌**阻塞**在最前面。

Trick 1：洞悉消耗规则与“最小值阻塞”（绝对的注意力跳跃）

如果我们尝试像常规的田忌赛马那样去逐个贪心比对，会陷入极度复杂的动态消耗状态中。

**关键跳跃**：观察失败方的惩罚——**输牌方卡牌保留在最前**。

这意味着，如果小红的手牌顶是一张数字极其小的牌，只要小茉打出一张比它大的牌赢下这一轮，小茉的牌消耗了，但**小红的这张极小牌依然会死死卡在牌库顶**！

而游戏进行中，手牌最小值 $B_{min}$一定会成为第一张，由于它是极小值，小茉后续打出的任何正常牌都会继续比它大，从而**持续不断地从它身上刷分**，直到小茉把手里的正常牌全部打光！



## D **时间二分与前缀跳跃贪心覆盖**

------

**一句话题意**

给定一个长度为 $n$ 的数字序列 $a$（$a_i > 0$ 表示白色，$a_i = 0$ 表示黑色）。

在第 0 秒，你可以至多选择 $k$ 个**白色**元素染红。此后每秒，所有现存的红色元素 $i$ 会将其右侧范围 $[i+1, \min(n, i+a_i)]$ 内的所有**白色**元素染红（黑色元素免疫且无需被染）。

求将**所有白色元素全部染红**的**最短时间**（秒数）。若无论如何都无法完成，输出 `-1`。

- **核心特征**：黑色元素是“隐形”的（不产生辐射，也不需要被覆盖）；红色染色的扩展过程随着时间呈现**指数/瀑布式**增长，但实际上具有极强的**右向单调覆盖性质**。

------

**思维 Trick (关键跳跃)**

本题的核心思维跳跃在于“答案单调性（二分转化）”**与**“辐射接力的局部最优策略（贪心跳跃）”。

Trick 1：正难则反与答案单调性（将动态演化转化为静态校验）

如果顺着时间轴思考“第 $t$ 秒哪些格子红了”，状态会随着多点并发辐射变得极其混乱。

**关键跳跃**：注意到时间的性质——如果 $t$ 秒内能全染红，那么 $t+1$ 秒必然也能；如果 $t$ 秒不能，那么 $t-1$ 秒必然也不能。答案具有绝对的**单调性**。

因此，直接**二分答案时间 $mid$**。问题瞬间降维成一个极简的静态判定型问题：**“给你 $k$ 个初始红点和 $mid$ 秒时间，你能向右覆盖的最远白点下标是多少？”**

Trick 2：前缀最大延伸的贪心跳跃（化解并发扩展的后效性）

在给定了允许演化的时间 $mid$ 秒后，我们应该如何放置这 $k$ 个初始红点？

- **贪心起点**：为了不浪费覆盖范围，第一个红点显然应该直接放在**全序列最靠左的第一个白点**上。

- **单点在 $mid$ 秒内的极限辐射**：一个处于位置 $cur$ 的红点，在 1 秒内能辐射到的最右侧范围是 $cur + a_{cur}$。

  如果被它辐射到的新红点在下一秒继续向右接力辐射，那么在这个区间 $[1, cur]$ 内任何已经红了的点，都可以作为下一秒辐射的跳板。

  **极其美妙的性质**：为了在下一秒达到最远边界，我们根本不需要关心具体是哪个点在辐射，只需要知道**在当前已被覆盖的前缀区间 $[1, cur]$ 中，所有点能辐射出的右边界的最大值**是多少！

  定义前缀最大辐射边界：

  $$pre[i] = \max_{1 \le x \le i} (x + a_x)$$

  于是，单次接力扩展的转移方程直接坍缩为：

  $$cur \leftarrow pre[cur]$$

  执行至多 $mid$ 次接力扩展后，$cur$ 即为当前初始点所能覆盖的连通块极限右边界。

Trick 3：连通块断档与新起点分配

当一个初始红点耗尽了 $mid$ 次跳跃，或者它陷入了死锁（即 $pre[cur] \le cur$，无法再向右延伸）时，说明当前连通块已经达到了极限。

此时，我们消耗掉了一个 $k$ 的名额。为了继续向右推进，我们必须跨过当前的死胡同：

- 令 $cur \leftarrow cur + 1$。
- 过滤掉沿途所有不需要染色的**黑色元素**（因为它们不影响正确性），找到下一个未被染色的**白色元素**。
- 将下一个初始红点放置在此处，开启新一轮的 $mid$ 次贪心跳跃。

最终，若在消耗完 $k$ 个名额后，$cur$ 成功越过了序列终点（即不存在未染色的白点），则当前时间 $mid$ 合法。

------

**编码 Trick (优雅实现)**

你的 AC 代码极其简练，完美展现了 XCPC 竞赛中“预处理剥离逻辑”与“游标单调推进”的高级编码美学：

- **编码 Trick 1：利用前缀和思想预处理 $pre$ 数组（$O(1)$ 状态转移）**

  在输入阶段，你直接顺手完成了 $pre$ 数组的递推：

  ```从pp
  pre[i] = max(pre[i - 1], min(n, a[i] + i));
  ```

  将后续二分 `check` 中的寻路复杂度从 $O(N)$ 降至绝对的 $O(1)$，使得单次判定仅需模拟实际跳跃次数，极其高效。

- **编码 Trick 2：游标过滤黑点的统一抽象（极其稳健的边界防御）**

  在处理无需染色的黑点时，你写了一个极简的 `while` 循环抽象：

  ```cpp
  while(cur <= n && !a[cur]) cur++;
  ```

  这个逻辑被完美复用在了**起始定位**和**每次消耗名额后的新起点定位**中。这种游标单向顺推的写法天然免疫各种跳跃断档和下标越界失误。



## F **极值区间交集锁定与并查集去重填数**

------

**一句话题意**

构造长度为 $n$ 的全排列 $p$，需满足 $m$ 条限制，每条限制形如：区间 $[l_i, r_i]$ 中的**最大值恰好等于** $k_i$。求合法排列总数 $\pmod{998244353}$。

- **核心特征**：排列数字互不相同；**限制条件为最大值**，这意味着若若干个区间都以某个数 $v$ 为最大值，则 $v$ 必须落在这些区间的**公共交集**内，且这些区间的并集内不能有大于 $v$ 的数。

------

**思维 Trick (关键跳跃)**

本题的核心跳跃在于“由小到大确定上限（并查集染色）”**与**“由大到小反向填数（容错计数）”。

Trick 1：由限制值域升序处理，利用并查集锁定“绝对上限”（极值覆盖论）

面对杂乱的区间限制，若直接考虑某个位置填什么会互相掣肘。

**关键跳跃**：注意到如果要求区间 $[l, r]$ 的最大值为 $v$，那么该区间内的所有位置 $j$ 都必须满足 $p_j \le v$。

为了找出每个位置 $j$ 理论上能填的**最大上限 $U_j$**，我们按照限制权值 $v$ **从 $1$ 到 $n$ 升序**遍历所有限制区间 $[l, r]$，把区间内的所有位置的上限标记为当前的 $v$。

- 为什么是升序？因为后续更大的 $v'$ 如果覆盖了同样的位置，说明该位置既要 $\le v$ 又要 $\le v'$，上限显然应当被较小的 $v$ 锁死。
- **并查集跳跃去重**：为了高效完成区间覆盖，利用类似“并查集删除点”的经典 Trick。初始每个点指向自己，一旦位置 $j$ 被标记上限 $U_j = v$，立刻通过 `dsu.merge(j + 1, j)` 将其指向右侧尚未被覆盖的第一个点。这保证了全序列每个位置**仅被访问并标记一次**，完美均摊耗时。

Trick 2：极值共存的充要条件（交集缩点）

对于某个受到限制的权值 $v$，假设有多个区间都要求最大值为 $v$。

- $v$ 必须同时存在于这些所有区间中，因此 $v$ 的落点必须在这些区间的**公共交集** $[\max(l_i), \min(r_i)]$ 内（即代码中的 $[L_v, R_v]$）。
- 同时，落点位置 $j$ 的理论上限必须恰好保留为 $v$（即 $U_j = v$）。如果交集内的某个位置被更小的限制提前锁死（$U_j < v$），则 $v$ 不能填在此处。
- 定义 $v$ 的合法自由落点数 $free_v$ 为交集 $[L_v, R_v]$ 内满足 $U_j = v$ 的位置个数。若 $free_v = 0$ 且 $v$ 存在限制，则说明交集为空或被占满，方案数直接归零。

Trick 3：降序填数消解大小约束（无后效性组合乘法）

确定了每个位置的上限后，如何计算排列数？

如果从小到大填数，填入小值会占用大值的候选槽位，后效性极强。

**绝妙反转**：我们考虑数字 $v$ **从 $n$ 到 $1$ 降序填入**排列中！

当准备填入数字 $v$ 时，所有比 $v$ 大的数字已经填完。此时序列中所有上限满足 $U_j \ge v$ 的空位（假设当前共有 $cur$ 个），**每一个都绝对安全**，因为后续填入的数字全比 $v$ 小，绝对不会打破“$v$ 是局部最大值”的约束。

- **情况 A（数字 $v$ 带有区间限制）**：为了满足最大值条件，$v$ 必须精确落在其专属交集的候选点中。候选槽位仅有 $free_v$ 个，方案数 $\times free_v$。填入后消耗一个可用空位（$cur \leftarrow cur - 1$）。
- **情况 B（数字 $v$ 没有任何限制）**：$v$ 可以自由充当“普通数字”，塞入当前任何一个合法的空位中均可。候选槽位有 $cur$ 个，方案数 $\times cur$。填入后同样消耗一个可用空位。
- **动态空位维护**：随着 $v$ 向下递减，原本那些上限 $U_j = v$ 的位置，在处理更小的数时将被解锁为合法空位（即代码中的 `cur += cnt[v]`）。

------

**编码 Trick (优雅实现)**

你的 AC 代码不仅思路极其连贯，还封装了非常标准的 XCPC 竞赛模板，降低了考场实现难度：

- **编码 Trick 1：并查集顺推区间覆盖（均摊 $O(N \alpha(N))$ 染色）**

  在多区间染色中，你采用：

  ```cpp
  for(int j = dsu.find(l); j <= r; j = dsu.find(j)) {
      U[j] = v;
      dsu.merge(j + 1, j);
  }
  ```

  直接将已经染色的点向右合并到 `j + 1`。不仅常数远小于线段树，而且天然完成了交集候选点 $free_v$ 和解锁池 $cnt_v$ 的同步统计，逻辑高度内聚。

- **编码 Trick 2：极值变量的完美初值设定**

  在求交集时，直接初始化 `L` 数组为 0，`R` 数组为 `n`。对于没有任何限制的 $v$，其交集天然为全集 $[0, n]$，但由于后续计算直接通过 `info[v].empty()` 分流，完全隔绝了未限制数字访问到无效交集的边界隐患。



## **G 区间翻转最值】LCP 贪心与低位全 9 构造**

**极简题意**

给定区间 $[l, r]$（$1 \le l \le r \le 10^{15}$），求区间内所有整数在**十进制翻转并去除前导零**后得到的数的最大值。

------

**思维 Trick (关键跳跃)**

1. **转换目标（贡献倒置）**：

   翻转后的数最大 $\iff$ 翻转后的高位尽可能大 $\iff$ **原数的低位尽可能为 9**。

   *思考路径*：与其枚举数去翻转，不如在区间内直接构造一个**后缀全 9**的数。

2. **跨位数的降维打击**：

   如果 $l$ 和 $r$ 的十进制位数不同，区间内必定包含至少一个形如 $99\dots9$ 的数（即 $10^k-1$）。全 9 翻转后依然是全 9，且毫无前导零损失，必然是同位数下的全局最优解。

3. **同位数的 LCP 贪心构造（核心注意力）**：

   当 $l$ 和 $r$ 位数相同时，答案的瓶颈在于高位限制。

   设 $l$ 和 $r$ 的最长公共前缀（LCP）对应的高位部分是固定的。为了让后面的低位全变成 9，我们只需看 $r$ 在离开 LCP 后的**第一个分歧位**：

   - 将 $r$ 的这一位 **减 1**，其后所有更低位 **全部填 9**。
   - 这样构造出的数既能保证 $\ge l$ 且 $\le r$，又能让后缀贪心地拥有最多的 9。
   - **最终答案候选仅有两个**：$r$ 本身，以及构造出的后缀全 9 数。

------

**编码 Trick (优雅实现)**

你的 AC 代码中包含了非常经典的 XCPC 优雅编码习惯，大幅降低了思维和断点调试难度：

1. **利用 `max(l, p)` 消除跨位数分类讨论**：

   算出 $r$ 的最高位权值 $p$（如 $r=1234, p=1000$）后，直接令 `l = max(l, p)`。

   这一步极其巧妙：如果原本 $l < p$（跨位数），强制把 $l$ 抬高到同位数的下界 $10^k$。后续逻辑构造出的数恰好会是 $10^k - 1 = 99\dots9$，完美将“跨位数”与“同位数”的构造逻辑归一化。

2. **整除权值法寻找 LCP（免转字符串）**：

   寻找第一个不同位时，没有转成 `string` 去逐位对比下标，而是直接用数学性质：

   ```cpp
   p = 1;
   while(l / p != r / p) p *= 10;
   p /= 10;
   ```

   直接定位到分歧位的权值 $p$。不仅常数极小，且避免了字符串下标与数字权值互相转换的思维负担。

3. **极简后缀抹零与构造**：

   利用 `r / p * p - 1` 一步到位完成“分歧位减 1，后缀全变 9”的构造（例如 $1289 / 10 * 10 - 1 \to 1280 - 1 \to 1279$），优雅且绝对不会出现越界或进退位 BUG。





## H **二进制正交段划分与双指针 DP**

------

一句话题意

给定 $n$ 个数的序列 $a_1, a_2, \dots, a_n$，中间原为连加表达式。可将任意加号 `+` 改为按位或 `|`。

**注意规则**：本题约定 **`|` 的优先级高于 `+`**。

求有多少种替换方案，使得新表达式的计算结果与原式结果（即纯粹的总和 $\sum a_i$）完全相等？答案对 $998244353$ 取模。

- **核心特征**：运算优先级颠倒（`|` 先算，`+` 后算）。这意味着连续的 `|` 会将序列划分为若干个独立的连通块，块内先求或和，各块结果再相加。

------

**思维 Trick (关键跳跃)**

本题最震撼的跃迁在于“利用代数不等式压榨位运算性质，将守恒方程降维成不相交/正交条件”。

**Trick 1：优先级转化下的块状结构重塑**

什么时候或和等于累加和？

当且仅当块内所有数字在二进制表示下的 `1` **互不冲突**！

- 只要存在任意两个数在某一个二进制位上同为 `1`，那么在算按位或时该位的贡献只算一次（权值 $2^k$），而在算累加和时贡献算两次（权值 $2 \times 2^k$），必然导致或和严格小于累加和。
- **结论**：原题瞬间降维 —— 任何一种合法的修改方案，等价于**将序列划分为若干段，要求每一段内部所有元素的按位与运算全无冲突（即任意两个数的按位与为 0）**。

**Trick 2：单调性与双指针 DP 结合**

定义 $f[i]$ 表示将前 $i$ 个数合法切分完毕的方案数。

考虑最后一段切在 $[l, i]$，要求段内二进制正交。

- **单调性**：若段 $[l, i]$ 正交，那么其子段 $[l+1, i]$ 必然也正交；若发生冲突，向左扩展必然更冲突。

- 因此，对于每个右端点 $i$，存在一个**最靠左的极限安全边界 $L_i$**，使得只要 $l \ge L_i$，块 $[l, i]$ 内部就绝对不会发生二进制冲突。

- 状态转移方程：

  $$f[i] = \sum_{j=L_i-1}^{i-1} f[j]$$

- **优化**：$L_i$ 随 $i$ 递增而单调递增，直接用**双指针**维护当前正交块的左边界 $l$；区间和利用 $f$ 的**前缀和数组 $pre$** 实现 $O(1)$ 转移。整体时空复杂度被压榨到极致的 $O(N)$。

------

**编码 Trick (优雅实现)**

你的 AC 代码不仅完美闭环了上述逻辑，还展示了非常巧妙的位运算动态维护范式：

- **编码 Trick 1：加减法完美等价于位运算的进出维护**

  在移动双指针时，如何判断右端点加入是否冲突？如何剔除左端点？

  因为我们维护的区间内部**绝对正交（无位冲突）**，所以在当前合法区间内，**代数累加和 `sum` 与按位或和完全按位同构**！

  ```cpp
  while(sum & a[r]) {
      sum -= a[l]; // 直接用减法安全剥离左端点占用的二进制位
      l++;
  }
  sum |= a[r]; // 确认无冲突后，直接用按位或（或加法）并入新数字
  ```

  用极其轻量的 `&` 判定冲突，用单纯的减法弹出左侧元素，省去了开辟大小为 30 的位频次统计数组，极致优雅。

- **编码 Trick 2：前缀和下标的平移容错**

  在计算区间和 $\sum_{j=l-1}^{r-1} f[j]$ 时，等价于 $pre[r-1] - pre[l-2]$。

  代码中初始化 $pre[0] = f[0] = 1$，并且直接使用 `if(l - 2 >= 0)` 防御底层越界，逻辑自洽，无需对边界切分做任何多余的特判处理。





## I 核心Trick命名：**高低位区间划分与值域桥接**

------

**一句话题意**

给定区间 $[l, r]$，每次可选择区间内若干不同整数进行按位与（AND）操作，将结果加入集合 $\mathbb{S}$，求 $\mathbb{S}$ 能达到的最大 $\text{MEX}$。

------

**思路 Trick：关键思维跳跃**

XCPC 中位运算题目的核心往往在于**拆位**与**寻找独立分界点**。本题从“任意子集与”的复杂组合空间，跳跃到**高位分界点下的值域覆盖判定**，核心 Trick 可以拆解为以下三步：

1. **判 `0` 的一票否决（公共前缀截断）**

   位运算 AND 只能将 `1` 变 `0`。若 $l$ 和 $r$ 的二进制公共前缀中包含 `1`，说明区间内**所有数**在该位上均为 `1`。无论如何组合 AND，结果的该位必然保留 `1`，因此绝对无法凑出 `0`，此时 $\text{MEX}$ 直接为 `0`。

2. **最高不同位 $i$ 的高低位区间划分（核心结构剖析）**

   设 $l$ 和 $r$ 从高到低第一位不同的位置为 $i$（必然是 $l$ 该位为 `0`，$r$ 该位为 `1`）。这个分界点 $i$ 完美地将原区间切分为两个具有特殊性质的子集：

   - **左区间 $A = [l, 2^i-1]$**：第 $i$ 位均为 `0`。关键观察：**区间上限 $2^i-1$ 恰好是低位全 `1` 的掩码**。
   - **右区间 $B = [2^i, r]$**：第 $i$ 位均为 `1`。剥离第 $i$ 位后，剩余低位天然覆盖了连续值域 $[0, r - 2^i]$。

3. **值域桥接与贪心判定（“注意力”跳跃点）**

   - **$B$ 能无缝贡献的连续低位值域**：拿 $A$ 中的全 `1` 掩码 $2^i-1$ 去和 $B$ 中的单个数分别做 AND，可以直接洗掉 $B$ 的第 $i$ 位，从而直接凑出连续值域 $[0, lenB - 1]$，其中区间长度 $lenB = r - 2^i + 1$。
   - **仅用 $A$ 能保底的最小下界**：仅用 $A$ 内部元素做 AND，能产生的最小值就是 $A$ 中所有数的总 AND 和。设 $l$ 在第 $i$ 位以下最高位的 `0` 位于第 $j$ 位，则 $A$ 内部全员 AND 的结果恰好为 $L_{\text{base}}$（即 $l$ 抹去 $j$ 及更低位的值）。
   - **桥接逻辑**：我们目标是凑齐 $[0, l-1]$。既然 $B$ 能贡献从 $0$ 开始的连续段，只要这个连续段的上限 $lenB - 1$ 能够“够得着” $A$ 内部能生成的下界前序（即 $lenB \ge L_{\text{base}}$），断层就被弥补，所有 $< l$ 的数均可表出，答案直接保底达到 $r+1$；否则，断层处 $lenB$ 就是第一个无法凑出的数。

梳理一下因果链条，正确的逻辑推演过程是这样的：

1. **因为** $A$ 的最大值是 $2^i-1$（低位全 1 掩码）。
2. **所以** 它可以洗掉 $B$ 的第 $i$ 位，让 $B$ 贡献出从 $0$ 开始的低位连续段 $[0, lenB-1]$。
3. **又因为** $A$ 内部保底能凑出 $[L_{\text{base}}, 2^i-1]$。
4. **最终** 当这两段接上时（$lenB \ge L_{\text{base}}$），我们才凑齐了全部的前置数字，从而确定上界**至少能跨过 $2^i-1$，达到 $2^i$**。

------

**编码 Trick：优雅实现范式**

你的 AC 代码中展现了非常标准且高效的竞赛编码习惯，极大地降低了分类讨论的思维负担：

1. **遍历合一：融合前缀检查与分界点寻找**

   ```cpp
   if((l & r) >> i & 1) break; // 遇到公共 1，直接触发 break，ans 保持 0
   if((l ^ r) >> i & 1) { ... } // 极简捕获最高不同位
   ```

   没有单独写循环去截取字符串或计算前缀，而是在从高到低枚举位的同时，利用 `l & r` 顺手完成了“一票否决”判定。一旦在高位发现公共 `1` 直接退出，天然输出 `0`。

2. **按位取反 `~` 判定 `0` 掩码**

   ```cpp
   if(~l >> j & 1)
   ```

   寻找 $l$ 的次高位 `0` 时，利用 `~` 将目标 `0` 翻转为 `1` 再做位运算提取，省去了 `((l >> j & 1) == 0)` 的冗长写法，代码逻辑更连贯。

3. **利用移位截断极速构造 $L_{\text{base}}$**

   ```cpp
   ans >= (l >> j << j)
   ```

   **这是极其优雅的一步。** 需要将 $l$ 的末尾 $j$ 位清零时，没有去构造复杂的位掩码（如 `l & ~((1<<j)-1)`），而是直接利用 C++ 整数移位的截断特性右移再左移，清晰直白，做到零思维负担。

4. **单向状态流收束（避免提前 Return 陷阱）**

   整个逻辑中 `ans` 初始承载 $lenB$，满足桥接条件时跃迁为安全大值 `1 << i`，最后仅用一个干净的 `if(ans >= l) ans = r + 1;` 做终态收束。这种**线性状态流**有效避免了在多重嵌套中 `return` 导致的边界遗漏（例如特判 $l=0$ 等情况在此架构下被天然兼容）。



#### 关于 ”仅用 $A$ 内部元素做 AND，能产生的最小值就是 $A$ 中所有数的总 AND 和“：

这段话是整个算法中最精妙的**数学性质推导**之一。它解决的核心问题是：**在左区间 $A = [l, 2^i-1]$ 内部自由选择若干个数进行 $\text{AND}$ 操作，我们能凑出的最小值究竟是多少？**

我们可以将这段话拆解为两个核心层面的逻辑来深度剖析：

------

**第一层：为什么最小值一定是“全员 $\text{AND}$ 和”？**

**核心依据：按位与（$\text{AND}$）运算的单调递减性质。**

- $\text{AND}$ 运算的本质是“一票否决”。对于二进制的任意一位，只要参与运算的数中有一个 `0`，结果的这一位就是 `0`。
- 这意味着，**参与 $\text{AND}$ 运算的数越多，结果二进制中的 `1` 只会减少或保持不变，绝不可能增加**。结果的值必然单调不增。
- 既然我们的目标是寻找集合 $A$ 内部子集 $\text{AND}$ 能达到的**下界（最小值）**，那么把集合 $A$ 里的**所有数**全部拿来做 $\text{AND}$，得到的结果一定 $\le$ 任何真子集的 $\text{AND}$ 结果。

因此，下界严格等于区间连续 $\text{AND}$ 和：

$$L_{\text{base}} = \bigwedge_{x=l}^{2^i-1} x$$

------

**第二层：为什么全员 $\text{AND}$ 的结果恰好是 $l$ 抹去 $j$ 及更低位？**

**核心依据：连续整数自增时的“二进制进位清零效应”。**

已知集合 $A$ 的范围是 $[l, 2^i-1]$。注意上限 $2^i-1$ 的二进制形态是**第 $0$ 到 $i-1$ 位全为 `1`**。

我们设 $l$ 在第 $i$ 位之下，**从高到低第一个出现 `0` 的位置是第 $j$ 位**。

我们分三段来看区间 $[l, 2^i-1]$ 内所有数在二进制位上的表现：

1. **高于 $j$ 的位（第 $j+1$ 到 $i-1$ 位）**

- 既然第 $j$ 位是“从高到低第一个 `0`”，说明 $l$ 在第 $j+1$ 到 $i-1$ 位上**全部都是 `1`**。
- 在从 $l$ 连续 $+1$ 增长到上限 $2^i-1$ 的过程中，由于上限也是全 `1`，这一段高位永远不会发生进位翻转（它们始终保持为 `1`）。
- **结论**：区间内所有数在这些位上都是 `1`，全员 $\text{AND}$ 后，**高于 $j$ 的位原样保留 $l$ 的值（全为 `1`）**。

2. **第 $j$ 位本身**

- $l$ 自身的第 $j$ 位就是 `0`。
- 根据“一票否决”原理，既然 $l$ 参与了全员 $\text{AND}$，结果的第 $j$ 位必然被洗成 `0`。
- **结论**：全员 $\text{AND}$ 后，**第 $j$ 位必然为 `0`**。

3. **低于 $j$ 的位（第 $0$ 到 $j-1$ 位） —— 【关键跳跃点】**

- $l$ 的第 $j$ 位是 `0`。在从 $l$ 逐次 $+1$ 增长到 $2^i-1$ 的过程中，必然会经历一个关键时刻：**第 $j$ 位由 `0` 进位变成 `1`**。
- 根据二进制加法法则，当第 $j$ 位发生进位的瞬间，**低于 $j$ 的所有位（第 $0$ 到 $j-1$ 位）会全部清零**！
- 也就是说，区间内必然存在一个数 $x_{\text{carry}}$，它的第 $0$ 到 $j-1$ 位**全为 `0`**。既然区间里存在这样一个低位全 `0` 的数，全员 $\text{AND}$ 之后，结果的低位自然全部干干净净变成 `0`。
- **结论**：全员 $\text{AND}$ 后，**低于 $j$ 的位全部被洗成 `0`**。

------



#### 关于”如何得到[$L_{\text{base}}$，$l$]"：

把 $[L_{\text{base}}, l-1]$ 严丝合缝填满的，不是最高位掩码 $2^i-1$ 单枪匹马完成的，而是集合 $A$ 内部自然孕育出的一对“黄金搭档”**共同作用的结果。其中依然用到了“全 1 掩码清洗”的思想，只不过这次出场的是**局部低位全 1 掩码。

让我们把这最后一层硬核逻辑彻底捅破：

------

**核心揭秘：如何精准狙击 $[L_{\text{base}}, l-1]$ 里的任意数 $T$？**

已知目标数 $T$ 满足 $L_{\text{base}} \le T < l$。

从二进制视角看，$T$ 具有以下特征：

1. **高位（$>j$）**：和 $l$ 完全一样（全为 `1`）。
2. **第 $j$ 位**：必然是 `0`（因为 $L_{\text{base}}$ 该位为 `0`）。
3. **低位（$<j$）**：是某种特定的二进制组合（我们设它的低位数值为 $\text{mask}$）。即 $T = L_{\text{base}} + \text{mask}$。

因为 $T < l$，单选任何一个数都够不到它，我们必须用集合 $A$ 里的数做 $\text{AND}$。**实际上，只需要挑出两个特定的数，就能秒杀任意目标 $T$。**

**搭档一：提供目标形态的“原材料” $X$**

因为集合 $A$ 的上限直达 $2^i-1$，当数值自增跨过第 $j$ 位的进位点后，第 $j$ 位变成了 `1`。

在此之后，低 $j$ 位可以说是**应有尽有**（覆盖了从 $00\dots0$ 到 $11\dots1$ 的所有可能）。

因此，集合 $A$ 里**绝对存在**这样一个数 $X$：

$$X = T + 2^j$$

- 它的高位全 `1`，第 $j$ 位是 `1`，低 $j$ 位刚好就是我们想要的 $\text{mask}$。

**搭档二：负责局部清洗的“手术刀” $M$（局部掩码）**

既然 $X$ 的低位已经是正确答案了，唯独第 $j$ 位多了一个极其碍眼的 `1`。怎么干掉它？

我们需要在集合 $A$ 里找一个数，它的第 $j$ 位是 `0`，但低 $j$ 位**全为 `1`**。

这个数极其好找，它就是 $l$ 所在连续段自增到进位前的最后一个数：

$$M = L_{\text{base}} + 2^j - 1$$

- 它的二进制形态：高位全 `1`，**第 $j$ 位为 `0`**，**低 $j$ 位全为 `1`**。
- 既然 $l \le M < 2^i-1$，这个完美的局部掩码 $M$ **必然存在于集合 $A$ 中**！

------

**具象化碰撞演绎**

我们拿这两个数做一次 $\text{AND}$ 运算：

$$X \text{ AND } M$$

| **字段划分**    | **原材料 X**  | **局部掩码 M** | **AND 结果**      | **结果含义**           |
| --------------- | ------------- | -------------- | ----------------- | ---------------------- |
| **高位 ($>j$)** | 全 `1`        | 全 `1`         | **全 `1`**        | 完美保留高位           |
| **第 $j$ 位**   | `1`           | `0`            | **`0`**           | **精准洗掉多余的 `1`** |
| **低位 ($<j$)** | $\text{mask}$ | 全 `1`         | **$\text{mask}$** | 完美保留目标低位       |

**结果恰好严丝合缝地等于 $T$！**

------

**总结归纳**

回看你的问题，逻辑闭环如下：

1. 能凑出这一段，本质是利用了 **“带有目标低位的进位数 $X$”** $\text{AND}$ **“进位前的低位全 1 掩码 $M$”**。
2. 这里的功劳归属于 $M$（它本质上就是低 $j$ 位的 $2^j-1$ 掩码）。
3. **但是，为什么 $X$ 和 $M$ 能同时安全地存在于集合 $A$ 中？** 归根结底，依然是因为集合 $A$ 的上界足够包容（达到了 $2^i-1$），给予了充分的自增进位空间。



## J 稠密图稀疏化与线段树优化Prim

------

**一句话题意**

给定一张 $n$ 个点的无向完全图，点权为 $a_i$，任意两点间初始边权为 $a_u + a_v$。现删去其中的 $m$ 条边，求剩余图的最小生成树（MST）边权和。若不连通则输出 `-1`。

（数据范围：$n, m \le 3 \times 10^5$）

------

思路 Trick：关键思维跳跃

在 XCPC 竞赛中，面对“完全图删边求连通块/生成树”**这类经典模型，直接建图必然 TLE/MLE（边数高达 $O(n^2)$）。本题的核心 Trick 在于**利用数据结构将稠密边的松弛操作进行分段批量化，完成思维的跳跃：

1. **生成树算法的敏锐选型（Kruskal vs Prim）**

   - **Kruskal 视角**：依赖对边集排序，面对本题 $O(n^2 - m)$ 级别的剩余边毫无施展空间。
   - **Prim 视角**：基于点的扩展，每次寻找距离当前生成树集合最近的未加入点。虽然传统 Prim 每次找点需要遍历所有边，但其核心操作是“用新加入的点 $u$ 去更新其余所有点 $v$ 的距离”。这恰好对应了数据结构的区间修改！

2. **补图邻接表的“正难则反”与区间剖析（核心跳跃）**

   点 $u$ 和点 $v$ 之间的边权是 $a_u + a_v$。当点 $u$ 加入生成树集合时，它本该去更新所有未加入点 $v$ 的 $dis[v] = \min(dis[v], a_u + a_v)$。

   - 既然被删掉的边（原图的缺失边）只有 $m$ 条，我们只需记录每个点的“删边邻接表”（即在补图中的出边）。
   - 将点 $u$ 的删边邻接表从小到大排序后，这些被删掉的邻居节点就像“分界点”，将整个 $[1, n]$ 区间切割成了若干个**连续的有效区间**（保留边的区间）。
   - 于是，“用 $u$ 更新所有存在的邻居”瞬间等价于：**对若干个连续区间 $[L_k, R_k]$ 执行对 $a_v$ 的加法/取 Min 松弛**。

3. **权值分离与线段树节点设计（代数解耦）**

   如何在线段树中高效维护 $a_u + a_v$ 的最小值？

   - 关键观察：对于未加入生成树的点 $v$，$a_v$ 是静态不变的常数。
   - 当点 $u$ 试图去松弛区间时，它传递下去的实质只是自己的点权 $a_u$ 作为标记（Tag）。
   - 线段树节点内部只需静态维护区间内未加入点的最小 $a_v$（代码中的 `mn`），动态维护当前节点已被更新出的最小边权 $v = a_u + a_v$。这就成功解耦了边权的组合。

------

编码 Trick：优雅实现范式

你的 AC 代码不仅极具工程美感，且在线段树结构和边界处理上展现了极高的素养，大幅降低了树上二分或复杂分类讨论的思维难度：

1. **哨兵节点的极简分段过滤**

   ```cpp
   adj[i].emplace_back(0);
   adj[i].emplace_back(n + 1);
   sort(adj[i].begin(), adj[i].end());
   ```

   **这是极其优雅的编码习惯。** 面对邻接表切分区间 $[1, n]$ 的任务，如果在循环内特判开头和结尾会产生极丑陋的代码。通过直接向补图边集塞入 `0` 和 `n + 1` 两个虚拟节点并排序，后续遍历直接无脑取相邻两个元素 `[adj[x][i-1] + 1, adj[x][i] - 1]` 即可完美覆盖所有合法余区间，甚至天然兼容了空区间（线段树层面会自动 `return`），做到**零思维负担**。

2. **面向对象/泛型的 Lazy Segment Tree 模板架构**

   你的线段树采用了严格的 `Info`（节点信息）与 `Tag`（懒标记）分离的设计模式：

   - 将标记下传逻辑收束在 `Info::apply` 和 `Tag::apply` 内。

   - 运算符重载 `operator+` 专门处理 `pushup` 的合并逻辑。

     这种高内聚的写法杜绝了在 `modify` 或 `query` 递归中手写逻辑导致的低级失误（如漏下传、错合并），在紧张的 ICPC 赛场上能极大保证手速与正确率。

3. **无限大（`inf`）赋能的状态隐式删除**

   ```cpp
   tr.modify(x, {inf, -1, inf, -1});
   ```

   当点 $x$ 成功被选入生成树后，并没有采用复杂的数据结构去删点或维护并查集，而是直接利用单点修改将其内在属性 `mn` 和边权 `v` 统统覆写为 `inf`。在线段树的 `operator+` 逻辑下，它自然会被后续的查询彻底无视，实现了极简的“物理保留、逻辑删除”。

4. **初始起点的优雅锚定**

   ```cpp
   tr.modify(1, {a[1], 1, 0, 1}); // 让 1 号点边权为 0 直接内定出列
   ```

   Prim 算法通常需要单独处理起点的初始化。代码通过直接强行把节点 1 的生成树入边距离设为 `0`，使得第一轮循环查询全局最小值时必然精准命中节点 1，巧妙地将起点初始化逻辑无缝融入了后续 $n$ 轮的通用轮询中。
