## B **极小值截断与不变消耗前缀排列**

------

**一句话题意**

给定 $2n$ 张牌构成的全排列，平分为小茉（集合 $A$）和小红（固定序列 $B$）各 $n$ 张。游戏每轮对比双方牌库顶，大的一方得 $1$ 分并消耗该牌，小的一方不得分且牌**留在原地**。求小茉重新排列自己的手牌 $A$，使得自己**得分最大化**的不同排列方案数，对 $998244353$ 取模。

- **核心特征**：对手小红的出牌顺序 $B$ 是完全锁死且公开的。赢牌方消耗，输牌方卡牌**阻塞**在最前面。

Trick 1：洞悉消耗规则与“最小值阻塞”（绝对的注意力跳跃）

如果我们尝试像常规的田忌赛马那样去逐个贪心比对，会陷入极度复杂的动态消耗状态中。

**关键跳跃**：观察失败方的惩罚——**输牌方卡牌保留在最前**。

这意味着，如果小红的手牌顶是一张数字极其小的牌，只要小茉打出一张比它大的牌赢下这一轮，小茉的牌消耗了，但**小红的这张极小牌依然会死死卡在牌库顶**！

而游戏进行中，手牌最小值 $B_{min}$一定会成为第一张，由于它是极小值，小茉后续打出的任何正常牌都会继续比它大，从而**持续不断地从它身上刷分**，直到小茉把手里的正常牌全部打光！



## D **时间二分与前缀跳跃贪心覆盖**

------

**一句话题意**

给定一个长度为 $n$ 的数字序列 $a$（$a_i > 0$ 表示白色，$a_i = 0$ 表示黑色）。

在第 0 秒，你可以至多选择 $k$ 个**白色**元素染红。此后每秒，所有现存的红色元素 $i$ 会将其右侧范围 $[i+1, \min(n, i+a_i)]$ 内的所有**白色**元素染红（黑色元素免疫且无需被染）。

求将**所有白色元素全部染红**的**最短时间**（秒数）。若无论如何都无法完成，输出 `-1`。

- **核心特征**：黑色元素是“隐形”的（不产生辐射，也不需要被覆盖）；红色染色的扩展过程随着时间呈现**指数/瀑布式**增长，但实际上具有极强的**右向单调覆盖性质**。

------

**思维 Trick (关键跳跃)**

本题的核心思维跳跃在于“答案单调性（二分转化）”**与**“辐射接力的局部最优策略（贪心跳跃）”。

Trick 1：正难则反与答案单调性（将动态演化转化为静态校验）

如果顺着时间轴思考“第 $t$ 秒哪些格子红了”，状态会随着多点并发辐射变得极其混乱。

**关键跳跃**：注意到时间的性质——如果 $t$ 秒内能全染红，那么 $t+1$ 秒必然也能；如果 $t$ 秒不能，那么 $t-1$ 秒必然也不能。答案具有绝对的**单调性**。

因此，直接**二分答案时间 $mid$**。问题瞬间降维成一个极简的静态判定型问题：**“给你 $k$ 个初始红点和 $mid$ 秒时间，你能向右覆盖的最远白点下标是多少？”**

Trick 2：前缀最大延伸的贪心跳跃（化解并发扩展的后效性）

在给定了允许演化的时间 $mid$ 秒后，我们应该如何放置这 $k$ 个初始红点？

- **贪心起点**：为了不浪费覆盖范围，第一个红点显然应该直接放在**全序列最靠左的第一个白点**上。

- **单点在 $mid$ 秒内的极限辐射**：一个处于位置 $cur$ 的红点，在 1 秒内能辐射到的最右侧范围是 $cur + a_{cur}$。

  如果被它辐射到的新红点在下一秒继续向右接力辐射，那么在这个区间 $[1, cur]$ 内任何已经红了的点，都可以作为下一秒辐射的跳板。

  **极其美妙的性质**：为了在下一秒达到最远边界，我们根本不需要关心具体是哪个点在辐射，只需要知道**在当前已被覆盖的前缀区间 $[1, cur]$ 中，所有点能辐射出的右边界的最大值**是多少！

  定义前缀最大辐射边界：

  $$pre[i] = \max_{1 \le x \le i} (x + a_x)$$

  于是，单次接力扩展的转移方程直接坍缩为：

  $$cur \leftarrow pre[cur]$$

  执行至多 $mid$ 次接力扩展后，$cur$ 即为当前初始点所能覆盖的连通块极限右边界。

Trick 3：连通块断档与新起点分配

当一个初始红点耗尽了 $mid$ 次跳跃，或者它陷入了死锁（即 $pre[cur] \le cur$，无法再向右延伸）时，说明当前连通块已经达到了极限。

此时，我们消耗掉了一个 $k$ 的名额。为了继续向右推进，我们必须跨过当前的死胡同：

- 令 $cur \leftarrow cur + 1$。
- 过滤掉沿途所有不需要染色的**黑色元素**（因为它们不影响正确性），找到下一个未被染色的**白色元素**。
- 将下一个初始红点放置在此处，开启新一轮的 $mid$ 次贪心跳跃。

最终，若在消耗完 $k$ 个名额后，$cur$ 成功越过了序列终点（即不存在未染色的白点），则当前时间 $mid$ 合法。

------

### 编码 Trick (优雅实现)

你的 AC 代码极其简练，完美展现了 XCPC 竞赛中“预处理剥离逻辑”与“游标单调推进”的高级编码美学：

- **编码 Trick 1：利用前缀和思想预处理 $pre$ 数组（$O(1)$ 状态转移）**

  在输入阶段，你直接顺手完成了 $pre$ 数组的递推：

  ```从pp
  pre[i] = max(pre[i - 1], min(n, a[i] + i));
  ```

  将后续二分 `check` 中的寻路复杂度从 $O(N)$ 降至绝对的 $O(1)$，使得单次判定仅需模拟实际跳跃次数，极其高效。

- **编码 Trick 2：游标过滤黑点的统一抽象（极其稳健的边界防御）**

  在处理无需染色的黑点时，你写了一个极简的 `while` 循环抽象：

  ```cpp
  while(cur <= n && !a[cur]) cur++;
  ```

  这个逻辑被完美复用在了**起始定位**和**每次消耗名额后的新起点定位**中。这种游标单向顺推的写法天然免疫各种跳跃断档和下标越界失误。



## F **极值区间交集锁定与并查集去重填数**

------

**一句话题意**

构造长度为 $n$ 的全排列 $p$，需满足 $m$ 条限制，每条限制形如：区间 $[l_i, r_i]$ 中的**最大值恰好等于** $k_i$。求合法排列总数 $\pmod{998244353}$。

- **核心特征**：排列数字互不相同；**限制条件为最大值**，这意味着若若干个区间都以某个数 $v$ 为最大值，则 $v$ 必须落在这些区间的**公共交集**内，且这些区间的并集内不能有大于 $v$ 的数。

------

**思维 Trick (关键跳跃)**

本题的核心跳跃在于“由小到大确定上限（并查集染色）”**与**“由大到小反向填数（容错计数）”。

#### Trick 1：由限制值域升序处理，利用并查集锁定“绝对上限”（极值覆盖论）

面对杂乱的区间限制，若直接考虑某个位置填什么会互相掣肘。

**关键跳跃**：注意到如果要求区间 $[l, r]$ 的最大值为 $v$，那么该区间内的所有位置 $j$ 都必须满足 $p_j \le v$。

为了找出每个位置 $j$ 理论上能填的**最大上限 $U_j$**，我们按照限制权值 $v$ **从 $1$ 到 $n$ 升序**遍历所有限制区间 $[l, r]$，把区间内的所有位置的上限标记为当前的 $v$。

- 为什么是升序？因为后续更大的 $v'$ 如果覆盖了同样的位置，说明该位置既要 $\le v$ 又要 $\le v'$，上限显然应当被较小的 $v$ 锁死。
- **并查集跳跃去重**：为了高效完成区间覆盖，利用类似“并查集删除点”的经典 Trick。初始每个点指向自己，一旦位置 $j$ 被标记上限 $U_j = v$，立刻通过 `dsu.merge(j + 1, j)` 将其指向右侧尚未被覆盖的第一个点。这保证了全序列每个位置**仅被访问并标记一次**，完美均摊耗时。

#### Trick 2：极值共存的充要条件（交集缩点）

对于某个受到限制的权值 $v$，假设有多个区间都要求最大值为 $v$。

- $v$ 必须同时存在于这些所有区间中，因此 $v$ 的落点必须在这些区间的**公共交集** $[\max(l_i), \min(r_i)]$ 内（即代码中的 $[L_v, R_v]$）。
- 同时，落点位置 $j$ 的理论上限必须恰好保留为 $v$（即 $U_j = v$）。如果交集内的某个位置被更小的限制提前锁死（$U_j < v$），则 $v$ 不能填在此处。
- 定义 $v$ 的合法自由落点数 $free_v$ 为交集 $[L_v, R_v]$ 内满足 $U_j = v$ 的位置个数。若 $free_v = 0$ 且 $v$ 存在限制，则说明交集为空或被占满，方案数直接归零。

#### Trick 3：降序填数消解大小约束（无后效性组合乘法）

确定了每个位置的上限后，如何计算排列数？

如果从小到大填数，填入小值会占用大值的候选槽位，后效性极强。

**绝妙反转**：我们考虑数字 $v$ **从 $n$ 到 $1$ 降序填入**排列中！

当准备填入数字 $v$ 时，所有比 $v$ 大的数字已经填完。此时序列中所有上限满足 $U_j \ge v$ 的空位（假设当前共有 $cur$ 个），**每一个都绝对安全**，因为后续填入的数字全比 $v$ 小，绝对不会打破“$v$ 是局部最大值”的约束。

- **情况 A（数字 $v$ 带有区间限制）**：为了满足最大值条件，$v$ 必须精确落在其专属交集的候选点中。候选槽位仅有 $free_v$ 个，方案数 $\times free_v$。填入后消耗一个可用空位（$cur \leftarrow cur - 1$）。
- **情况 B（数字 $v$ 没有任何限制）**：$v$ 可以自由充当“普通数字”，塞入当前任何一个合法的空位中均可。候选槽位有 $cur$ 个，方案数 $\times cur$。填入后同样消耗一个可用空位。
- **动态空位维护**：随着 $v$ 向下递减，原本那些上限 $U_j = v$ 的位置，在处理更小的数时将被解锁为合法空位（即代码中的 `cur += cnt[v]`）。

------

**编码 Trick (优雅实现)**

你的 AC 代码不仅思路极其连贯，还封装了非常标准的 XCPC 竞赛模板，降低了考场实现难度：

- **编码 Trick 1：并查集顺推区间覆盖（均摊 $O(N \alpha(N))$ 染色）**

  在多区间染色中，你采用：

  ```cpp
  for(int j = dsu.find(l); j <= r; j = dsu.find(j)) {
      U[j] = v;
      dsu.merge(j + 1, j);
  }
  ```

  直接将已经染色的点向右合并到 `j + 1`。不仅常数远小于线段树，而且天然完成了交集候选点 $free_v$ 和解锁池 $cnt_v$ 的同步统计，逻辑高度内聚。

- **编码 Trick 2：极值变量的完美初值设定**

  在求交集时，直接初始化 `L` 数组为 0，`R` 数组为 `n`。对于没有任何限制的 $v$，其交集天然为全集 $[0, n]$，但由于后续计算直接通过 `info[v].empty()` 分流，完全隔绝了未限制数字访问到无效交集的边界隐患。
